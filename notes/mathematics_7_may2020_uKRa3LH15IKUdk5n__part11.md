## What This Section Does (content sequence)

The ordered content moves this section type makes:

1. **Topic carry-over** (dangling reference to the object from the prior section) — sets the reader's frame.
2. **Instantiation announcement** ("As an example… the function was set as:") — promises a concrete example.
3. **Display of the example form** (the equation) — delivers what was promised.
4. **Unpack in physical terms** ("Which is a function showing how… varies across its body") — translates math back into the physical situation.
5. **Stated purpose for the next manipulation** ("To plot figure 12… the function y(x) was solved for A and V") — justifies why algebra must now be done.
6. **Display of the manipulated form** — delivers the rewritten equation.
7. **Definition of the free variable** ("Where x represents…") — clarifies what is left to vary.
8. **Control statement** ("all parameters other than x were set as constant") — establishes the experimental conditions of the figure.
9. **Flagged upcoming finding** ("Interestingly figure 13 shows that") — primes the reader for an unexpected result.

WHY this order: each move answers a question the previous move raised. The carry-over (1) raises "what function?"; the announcement (2) says "here is one"; the equation (3) shows it; the unpack (4) says what it *means*; the purpose (5) raises "but what is it good for in a plot?"; the rewritten form (6) delivers that; the variable definition (7) says "here is what varies"; the control (8) says "and nothing else does"; the teaser (9) says "and look what happened when we did."

A student replicating this with a different topic would: (a) name the object under study, (b) display a sample function, (c) tell the reader what physical feature the function encodes, (d) state the analytical purpose for re-arranging the function, (e) show the re-arranged form, (f) define the variable that will be swept, (g) state that all other parameters are held constant, (h) tease an interesting finding.

### Skeleton A — Example-function paragraph
**SKELETON:** "[Topic reference, dangling]. As an example plot of this function for a [varying parameter], the function was set as: [formula]. Which is a [noun-phrase role] showing how the [physical feature] of a [shape-adjective] [object] varies across its [extent]."

1. **Slot 1 — Topic reference.** A dangling noun phrase carried over from the prior paragraph (no verb). Grammatical shape: bare noun / noun phrase.
   *Fill differently:* pick a single-word or two-word name of the object being modelled (e.g. "the pendulum", "the wing", "the blade").
2. **Slot 2 — "As an example plot of this function for a [varying parameter]".** A prepositional phrase naming which quantity will change. Shape: noun + participle.
   *Fill differently:* name the parameter you intend to sweep (e.g. "for a varying blade chord", "for a varying pendulum length").
3. **Slot 3 — "the function was set as:" + display equation.** A passive verb + colon + formula. Shape: "the [noun] was set as:" then the maths.
   *Fill differently:* write the specific formula your example will use.
4. **Slot 4 — "Which is a [role] showing how the [feature] of a [shape] [object] varies across its [extent]."** A relative clause unpacking the equation in physical terms. Shape: "Which is a function showing how… varies across…"

## Express-Idea Vocabulary

**Sequencing / instantiation:** "As an example plot of this function…" (announces a specific instantiation). "To plot figure 12 showing…" (introduces the next analytical step with its purpose attached).

**Cause / consequence:** "so the function returned to its original form" (justifies the algebraic manipulation by its outcome). "showing how varrying the radious… changes its depth" (encodes the cause→effect within a participle clause).

**Specification:** "Where x represents a multiple of the radius…" (defines a symbol in a trailing relative-style clause).

**Control / mechanism:** "all parameters other than x were set as constant" (passive construction declaring which variables are held fixed).

**Interest / verdict markers:** "Interestingly figure 13 shows that" (adverb-initial sentence flagging the upcoming finding as non-obvious).

**Explanation / definition verbs:** "is a funtion showing how" (treats the equation as a *depiction* of a physical variation). "was set as" (passive reporting verb for introducing a formula). "was solved for" (algebraic manipulation verb). "represents" (symbol-to-meaning definition verb).

## How to Explain an Idea (replication steps)

This section uses the **"function-display → physical-unpack → algebraic-rearrangement → variable-definition → experimental-control → flagged-finding"** pattern.

**Step-by-step replication for a new idea:**

1. **Anchor the object.** Open with a dangling one- or two-word noun phrase that points back to the thing being modelled (no verb needed).
2. **Announce a specific instantiation.** Write "As an example plot of this function for a [parameter that will vary], the function was set as:" — commit to showing a concrete formula.
3. **Display the example formula.** Use a centred display block so the reader can see it as an object.
4. **Unpack the formula physically.** Begin the next sentence with "Which is a function showing how the [feature] of a [shape-adjective] [object] varies across its [extent]." — translate math back into the real thing it represents.
5. **State the analytical purpose.** Begin a new sentence with "To plot [figure number] showing how [changing X] [affects Y], the [function] was solved for [symbols]…" — justify why you now rearrange the function.
6. **Show the rearranged formula.** Display the manipulated equation.
7. **Define the swept variable.** Add a sentence starting "Where [symbol] represents [physical meaning]." — never let a symbol float undefined.
8. **Declare the control.** Write "In [figure number] all parameters other than [key symbol] were set as constant." — name what is held fixed.
9. **Flag the next finding.** Begin a sentence with an interest marker ("Interestingly", "Notably", "Surprisingly") followed by the next figure reference and the verb "shows that" — tease what the reader is about to see.

The rhythm is: **show → say what you showed → say why you rearranged → show the rearrangement → name your variable → lock everything else down → raise the curtain on the result.**
