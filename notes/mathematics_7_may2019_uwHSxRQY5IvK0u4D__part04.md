## What This Section Does (content sequence)

This is a **modeling / function-construction** section. Its ordered moves are:

1. **Identify a mismatch between measured width and model width** (sets up the need for action).
2. **State the corrective action** (horizontal compression).
3. **Compute the scale factor** from the two widths.
4. **Apply the transformation** to the existing equation (show the algebra).
5. **Declare the new function found** (verdict sentence).
6. **Display the final formula** with its domain.
7. **Move to the next body part** and *contextualise* its geometry by pointing to a real-world cause.
8. **Justify the assumed cross-section** by appealing to the material's nature.
9. **Derive the modeling consequence** (no scaling needed).
10. **Define the function variable**.
11. **Display the formula**.
12. **Source a parameter from external software/data**.
13. **State the parameter value**.

The logic of the order: *problem → quantified fix → applied fix → result → next component → contextual justification → assumption → consequence → definition → formula → sourced parameter*. Each move either supplies the missing input for the next (e.g. factor enables application, assumption enables consequence) or announces the move that follows (e.g. "is found" → formula; "is following:" → value).

## How to Explain an Idea (replication steps)

This section runs on a **"transformation-of-existing-function + real-world-justified-new-function"** pattern. To explain a new idea with the same pattern:

1. **Name a mismatch**: state that a measured width differs from the model's current width.
2. **Name the fix**: pick horizontal compression *or* enlargement.
3. **Compute the scale factor** as the ratio of the two widths and give it to several decimals.
4. **Apply it visibly**: paste the factor under the x-terms of the old equation.
5. **Announce the result** with the formula "From the calculation above, function for the [part] [f(x)] is found."
6. **Write the new function** with its domain.
7. **Switch to the next body-part** and explain a visible surface feature by reference to a real-world object (clothing, accessory, anatomy).
8. **Justify the assumed cross-section** using the material/property of that object, via "Since … it is fair to assume …".
9. **Derive the modeling consequence** — usually that no further scaling is needed.
10. **Define the variable**: "Letting [v(x)] be the function of his [part] …"
11. **Display the formula**.
12. **Source a parameter** with "According to the information the software provides …".
13. **State the parameter value** as a single line.
