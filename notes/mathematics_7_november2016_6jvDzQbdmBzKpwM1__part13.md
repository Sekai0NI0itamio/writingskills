## What This Section Does (content sequence)

This is an **Extension of a previous result** section. The sequence is:

1. **Recall the previous case's conclusion** (so the reader is re-anchored to what was found).
2. **Quantify it numerically** (so the verdict in step 3 has something concrete to judge).
3. **Verdict on that result** ("anticlimactic") — gives the *reason* an extension is needed.
4. **Concessive pivot** ("however... can be extended") — opens the door to a new case.
5. **Counterfactual parameter change** ("if X were Y instead of Z") — sets up a single-variable perturbation.
6. **New figure reference + new headline claim** — replaces the prior conclusion with one for the new case.
7. **Numerical location of the new optimum** — the payoff.
8. **Symmetry / equivalent reading** — closes the geometric circle.

**Why that order:** the verdict in (3) is only meaningful *after* the result is quantified in (2); the pivot in (4) is only motivated *after* the verdict; the counterfactual in (5) is only believable *after* the reader accepts the framework is reusable. A student could replicate the sequence by: state old result → give number → judge it → "however, we can generalise" → change one parameter → show new figure → give new optimum → note symmetry.

## How to Explain an Idea (replication steps)

This section uses the **"recall → judge → extend"** pattern: you restate a result, evaluate it, then prove the framework is general by running one altered instance.

Steps to replicate with a new idea:

1. **Anchor to a previous figure** ("As Figure X shows…") — start by pointing at an already-existing result.
2. **State the optimum in symbols** ("[variable] is maximised when [parameter] = [value]") — give the technical headline.
3. **Translate it into plain language** ("i.e. when [physical/action description]") — add a parenthetical that grounds the symbol in the real scenario.
4. **Tag the relevant actor with a defining attribute** ("the slower raptor") — one post-nominal noun phrase that explains *why* this optimum occurs.
5. **Quantify with units** ("≈ 0.549 (seconds)") — give a number and its units so the reader can gauge magnitude.
6. **Issue a verdict** ("This is a rather [adjective] result") — evaluate honestly; this creates the need for the next move.
7. **Concede and pivot** ("however the [model] can be extended to other cases") — the pivot verb ("extended") tells the reader the section's job has changed.
8. **Open a counterfactual** ("If, for example, [parameter] were to be [new] instead of [old]…") — change exactly one input.
9. **Predict the new figure and its headline** ("the graph would be Figure Y, and [outcome] would be maximised") — keep the same criterion verb ("maximised") to show continuity.
10. **Locate the new optimum as an intersection** ("where A intersects B at [parameter] ≈ [angle]") — give the geometric/analytic handle.
11. **Mirror via symmetry** ("or equivalently due to symmetry, where A intersects C at [parameter] ≈ [complement]") — close the geometric picture by exhausting the symmetric pair.
