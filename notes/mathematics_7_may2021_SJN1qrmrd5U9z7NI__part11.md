## How to Explain an Idea (replication steps)

**Pattern:** Formula introduction → symbol definition → value provision → substitution → computation → result

1. State the formula you are about to use.
2. Define each symbol in the formula.
3. Provide the known numerical values for the symbols.
4. Substitute the values into the formula.
5. Perform the arithmetic step by step.
6. State the final computed result.
