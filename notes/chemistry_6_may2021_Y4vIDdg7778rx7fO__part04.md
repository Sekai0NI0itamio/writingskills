## What This Section Does (content sequence)

This is the **pre-data + transition** segment of an empirical chemistry write-up. The order is fixed:

1. **Compiled reference data table** (1st). Sets up comparison: experimental values in the section to come will be read against these literature values, so the table must appear **before** the discussion.
2. **Blank line / page marker** (2nd). Visually separates evidence from argument — standard IB scientific-report hygiene.
3. **Numbered sub-question pivot** (3rd). Announces the *next* independent variable ("number of carbon atoms") so the reader knows the discussion that follows is no longer about structure (primary/secondary/tertiary) but about chain length.
4. *(not in this excerpt)* → **Definition of carbon-atom count** (would come next): what counts as a carbon and what does not (e.g., branched vs. straight).
5. *(not in this excerpt)* → **Comparison across carbon numbers**: group entries by n=3, n=4, n=5 and observe enthalpy trends.

**Why this order**: a results/analysis section must (a) lay the benchmark data, (b) close the previous analytic axis with an explicit sentence, (c) open the next axis with a labelled question. Skipping the pivot leaves the reader unable to track which variable is being discussed.

## How to Explain an Idea (replication steps)

The pattern this section relies on is **benchmark-data deposit → sectional pivot**.

1. **Step 1 — Decide your analytical axes first** (e.g., carbon number, then branching class). Number them: 1, 2, 3.
2. **Step 2 — Compile one consolidated reference table** containing every member of the chemical family you will discuss, across *all* axes simultaneously. Columns must be identical in number and order for every row.
3. **Step 3 — Close the table with a blank line or page break** so the reader's eye registers the end of evidence.
4. **Step 4 — Write the pivot sentence**: "[n]. For the [next independent variable]:". Do **not** explain it here; the colon defers.
5. **Step 5 — In the paragraph that follows, open with a definition or observation** specific to that variable (e.g., "The number of carbon atoms refers to …"). This pattern lets the reader always know *which axis* is active in any given paragraph.
