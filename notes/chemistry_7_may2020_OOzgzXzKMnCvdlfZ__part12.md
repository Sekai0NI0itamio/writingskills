## How to Explain an Idea (replication steps)

**Pattern**: *General principle → formula definition → dual-instance demonstration → extended application with aggregation rule → worked arithmetic.* This is a **definition-then-exemplification-then-extension** pattern, where each move adds a layer of concreteness on top of the abstract rule.

1. **Anchor the idea in a named principle** — state which broader law or concept makes the measurement worth quantifying, using a fragment or clause that completes a prior sentence.
2. **Define the general calculation rule** — write the formula as an equation, naming each component and the final operation, and reference any supporting table or source.
3. **Demonstrate the rule with two specific instances** — pick one condition (e.g., one temperature), apply the formula to two different apparatus or variables, and show each arithmetic result as a percentage.
4. **Extend to a more complex measurement and define the aggregation method** — state that the same formula was applied across multiple trials, then name the statistical operation (e.g., mean) used to combine individual results into one representative value.
5. **Write out the full arithmetic with real numbers** — display the complete calculation (sum of divisions divided by count) and state the final percentage, closing the section with tangible proof.
