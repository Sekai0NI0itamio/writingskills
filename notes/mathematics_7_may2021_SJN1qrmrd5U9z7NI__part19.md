## What This Section Does (content sequence)

This is a **supporting-data appendix**, not an argument. Its move-order is fixed by function:

1. **Raw repeated measurements first** — the bulk must appear before any label, because the numbers are the *evidence*; the reader cannot judge a calculation without seeing the input data.
2. **Parallel column structure across all rows** — two measurement blocks (six columns left, five columns right) sit side-by-side so the reader can compute the percentage-error quantity (inferred title) between them row by row.
3. **Title/identifier last** — placed *after* the table because appendices are referenced, not read sequentially; the label tells a returning reader (or examiner) what to expect before they reopen it.

A student replicating this on another topic should: (a) place data before description, (b) keep column structure identical row-to-row so a calculation can be re-done by eye, (c) label the appendix *after* the table to signal "reference material."

## Express-Idea Vocabulary

Because the section is data, almost **no connective vocabulary is used**. The only idea-expressing language appears in the title:

- **Specification / scope-narrowing**: "for Equation 2" — restricts the calculation to a single named referent.
- **Categorising label**: "Appendix 5" — positions the section within a numbering system.
- **Process noun**: "Calculations" — names the operation the data supports.
- **Measurement-uncertainty term**: "Percentage Error" — the technical concept the rows operationalise.

There are no sequencing words ("firstly", "following this"), no cause markers ("therefore", "hence"), no contrast words ("however", "whereas"), no specification markers ("in particular", "that is"), no evidence-handling phrases ("according to", "this suggests"). A reader learns *nothing* about logical progression from this section in isolation — its job is to be the *thing* other sections reason about.

## How to Explain an Idea (replication steps)

The pattern here is **not explanation** — it is **evidence-deposit**. The section's job is to lay out raw material that an *earlier* section will then explain using the connectives listed above. To replicate:

1. **Identify the calculation/quantity** your main argument will justify (e.g., "Equation 2," "Titration 2").
2. **Decide the anchor variable** — the one column whose values you will sort on, so the reader can see the trend at a glance (here: leftmost column, 368 → 306, strictly decreasing).
3. **Collect raw trials**, each producing a full set of dependent measurements; paste them as whitespace‑delimited rows in the same column order every time.
4. **Sort the rows** by the anchor column (here descending), so the visual descent *is* the argument.
5. **Place the table first**, then a one-line title of the form *Appendix [number]: [Operation phrase] for [named object]* — three noun phrases, no verbs, so the reader instantly classifies the unit as reference material.

The pattern is therefore: **name-the-quantity-in-advance → present-trials-in-anchor-sorted-order → label-retrospectively**. The "idea" being expressed is only the *promise* that the data exists; the explanation of what it means belongs in another section that will use sequencing, cause, and contrast vocabulary that this appendix deliberately avoids.
