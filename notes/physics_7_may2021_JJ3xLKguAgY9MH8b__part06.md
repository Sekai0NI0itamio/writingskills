## What This Section Does (content sequence)

This is a **"results/raw data"** section. The ordered content moves a 6/7 IB Physics IA makes here are:

1. **Method hand-back** — re-name the uncertainty procedure the figure is about to illustrate.
2. **Worked exemplar** — show *one* measurement read off the instrument, with its bounded interval and final value-with-uncertainty.
3. **Variable declaration row** — name the independent and dependent variables, their units, and the instrument/reading uncertainties before any numbers appear.
4. **Replication index** — label trial columns (1…n) to show that repeat measurements were taken.
5. **Systematic data block** — sweep the independent variable across its full range in uniform steps, with all repeats recorded per step.
6. **Artefact label** — number the table and classify it ("Raw data") so it can be cross-referenced.

**Why this order works:** (1) re-grounds the reader in the *method* so the worked example that follows has a framework; (2) lets the reader see how *one* cell was produced (and so trust the rest); (3) defines the columns so the eye knows what it's scanning; (4) declares reliability through replication *before* the numbers land; (5) delivers the full dataset as a single scannable block; (6) closes with a reference handle for later analysis. A student replicating this on, say, pendulum length vs period, would: name the uncertainty step → show one timing with ± → declare "Length L /m ± 0.001" and "Period T /s ± 0.01" → label T₁…T₁₀ → tabulate ten lengths × ten repeats → caption "Table 1: Raw data."

## Paragraph Skeletons (replicable templates)

**Skeleton A — Worked exemplar of one measurement**
> SKELETON: "**[referenced method]** is used to get the [quantity sought]. [reference feature] is between [lower bound] [unit] and [upper bound] [unit]. This gives the value: [central value] [unit] ± [half-range] [unit]."

1. *Slot 1 (method hand-back, clause)* — name the analytical tool already derived upstream.
2. *Slot 2 (spatial anchor, sentence)* — specify the physical feature being read on the object/photograph, with units bracketed by "between … and …".
3. *Slot 3 (resolved value, sentence)* — deliver the midpoint, unit, ± and half-range.
4. **How to fill with a new idea:** pick a measurement you took from a single image or scale; in slot 1 cite the upstream equation that needs the number; in slot 2 locate the visual anchor (a meniscus, a ball-edge, a rule-mark) and bracket its bounds to the smallest instrument division; in slot 3 average the bounds and write ± half the interval.
5. **Original fill:** "get the absolute uncertainty in the mean. The middle of the ball is between 2.04 m and 2.05 m. This gives the value: 2.045 m ± 0.005 m."
6. **Demonstration fill (different idea):** "**Hooke's law gradient** is used to get the spring constant. The top of the spring at full extension is between 12.2 cm and 12.3 cm. This gives the value: 12.25 cm ± 0.05 cm."

**Skeleton B — Table title row (variable declaration)**
> SKELETON: "[Independent variable] [symbol]/[unit] ± [Δindependent]  |  [Dependent variable] [symbol]/[unit] ± [Δdependent]"

1. *Slot 1 (independent variable header)* — name, Greek/Latin symbol, units, instrument uncertainty.
2. *Slot 2 (dependent variable header)* — same shape, different symbol.
3. **How to fill:** decide which axis is *set* and which is *measured*; in slot 1 write the controlled quantity with the smallest step you can reliably set; in slot 2 write the measured quantity with the resolution of your instrument.
4. **Original fill:** "Incline angle α/° ± 1 | Range xα /m ± 0.005 m"
5. **Demonstration fill (different idea):** "Applied force F /N ± 0.05 | Extension e /mm ± 0.5"

**Skeleton C — Tabular body (systematic evidence block)**
> SKELETON: "[α row] = value → [trial 1], [trial 2], … [trial n]"  *repeated for each step of α.*

1. *Row label* — single value of the independent variable.
2. *Row entries* — n repeat measurements of the dependent variable, in identical precision.
3. **How to fill:** choose a uniform step for α that spans the practical range; for each α, record n repeats in the same unit/precision as the header; keep rows in monotonic α order so a trend is visible at a glance.
4. **Original fill:** "0 → 2.105, 2.135, 2.125, 2.135, 2.125, 2.115, 2.105, 2.115" (8 repeats per row, α in 5° steps from 0 to 65).
5. **Demonstration fill:** "0.20 → 1.81, 1.83, 1.79, 1.82, 1.80, 1.81, 1.84, 1.79" (n = 8, F in 0.05 N steps).

**Skeleton D — Table caption**
> SKELETON: "Table [n]: [one- or two-word classification of contents]."

1. *Slot 1 (table index)* — increment to match the rest of the report.
2. *Slot 2 (content label)* — name what *kind* of data (Raw, Processed, Calculated) so the reader knows the stage of the analysis.
3. **How to fill:** if the table contains untouched measurements, label "Raw data"; if it contains derived means, label "Processed data" or "Mean values."
4. **Original fill:** "Table 1: Raw data."
5. **Demonstration fill:** "Table 2: Mean period and standard deviation."

## How to Explain an Idea (replication steps)

The section uses a **worked-exemplar → systematic-tabulation → label** pattern (a "show one, show all, name it" evidence-presentation pattern). To replicate it for a NEW experiment, take these steps in order:

1. **Hand back to upstream method.** Open with one clause that names the analytical tool or quantity the reader needs (e.g. "Hooke's law is used to get…"). This re-anchors the reader in *why* the table is being shown.
2. **Demonstrate the method on a single instance.** Pick one measurement (one image, one reading) and bracket it: state the lower bound, the upper bound, and the same unit on both sides. This shows the reader *how* every later cell was produced.
3. **Resolve the instance into value ± uncertainty.** Use "This gives the value: X ± Y" to convert the interval into a single reportable number. This teaches the precision the rest of the table inherits.
4. **Declare the table's column variables.** Write a header row that names each column with: symbol, unit, and instrument uncertainty (e.g. "F /N ± 0.05"). Do this *before* any numbers appear so the eye knows the column's meaning.
5. **Declare the replication count.** Sub-header the trial columns (₁, ₂, … ₙ) to signal that repeat measurements exist; the number chosen should match what you actually took.
6. **Lay down the systematic evidence block.** Sweep the independent variable in uniform steps across its full practical range; record all n repeats per step, in identical precision, with rows in monotonic order.
7. **Label the artefact.** Close with "Table *n*: *[Raw / Processed / Mean] data*." This both numbers the table for cross-reference and pre-classifies its analytical stage.
8. **Resist adding interpretation.** At this section stage, the job is to *present*, not to *argue*. Any "therefore" or "we see that" sentences belong in the *next* section (analysis), not here.
