## Paragraph Flow (move by move)

**Paragraph 1** (general form + variable definitions)

1. **Authority claim** — "One equation used by scientists (Robert C. Reid, 1987)" — establishes that this isn't the student's own invention but a known model. → Hand-off: because it's a known model, the reader needs to see *what shape* it takes, so the equation follows.
2. **Model presentation (display)** — "η = AT B" — gives the symbolic form so variables can then be unpacked. → Hand-off: the bare equation demands labels for each symbol.
3. **Variable definition + parameter naming** — "η is viscosity in cP, T is the temperature in Kelvin" plus "A and B are constants to be found" — assigns units to the dependent/independent variables and flags the unknown parameters as the investigation's target. → Hand-off: the constants are flagged as "to be found," which creates the need for the *specific* literature values next.

**Paragraph 2** (specific literature values → unit conversion → bridge to data)

4. **Bridge claim** — "The equation found by Robert C. Reid … is the following:" — uses "the following" to zoom from the abstract form into a concrete instance. → Hand-off: the reader is primed to receive numbers.
5. **Specific model presentation (display)** — "η = (3.4263 × 10⁷³)T⁻²⁸·⁵²" — delivers the concrete numeric version. → Hand-off: the numbers now need to be split back out to match the A and B labels just given.
6. **Unpack / parameter identification** — "A = 3.4263 × 10⁷³ and B = −28.52" — labels each coefficient so the reader can locate them on a curve-fit later. → Hand-off: with both student and literature values in play, the section must justify *why* a comparison is even possible (units differ).
7. **Purpose statement** — "To be able to compare, I have converted …" — declares the rationale (comparison) that drives the conversion work. → Hand-off: the purpose (compare) demands the mechanics of conversion be shown.
8. **First conversion rule (Kelvin)** — "x + 273.15" — delivers the temperature conversion, isolated in its own sentence. → Hand-off: temperature was handled first because it's simpler; viscosity units need more derivation.
9. **Dual definition / contrast** — "Poises, on the other hand, is defined as … whereas Pascal second is …" — sets up the *two* unit systems side by side so a bridge can be built. → Hand-off: contrast demands a derivation step that resolves it.
10. **Derivation / consequence chain** — "We know 1kg = 1000g and 1cm = 0.01m, hence 1P as = …" — uses "hence" to convert the contrast into a single numeric ratio (10P). → Hand-off: once the ratio is proven, the converted values are ready to be used, so the data section follows.
11. **Result-bridge / transition** — "The converted values are found in the tables below … to compare coefficients A and B:" — closes the paragraph by *promising* the visual comparison, handing the reader to the next section (tables/graphs).

## What This Section Does (content sequence)

This is a **model-introduction + unit-justification** section. The logical order is:

1. **Authority citation** — anchors the model as established, not invented. Sets up trust before the equation is shown.
2. **General symbolic form** — lets the reader see the shape of the relationship before any numbers appear.
3. **Variable + parameter definitions** — names what is measured (η, T) and what must be found (A, B). This is what makes the rest of the section meaningful: A and B become the *target* of the experiment.
4. **Concrete literature instance** — plugs real numbers into the same form so the reader can match coefficients.
5. **Parameter unpacking** — labels which number is A and which is B; lets the student's later curve-fit be compared term-by-term.
6. **Comparison-purpose statement** — *why* a conversion is about to happen; without it the unit work feels arbitrary.
7. **Simple unit conversion (temperature)** — handled first because it is one-line.
8. **Dual unit-system definition (viscosity)** — needed because the literature and student data use different conventions.
9. **Derivation of conversion ratio** — proves the bridge numerically with "hence."
11. **Result bridge** — promises the tables/graph where the conversion pays off.

The reason for *this* order: **establish → specialise → justify-comparison → convert → deliver**. A reader must see (1) the model exists, (2) what it looks like, (3) what unknowns matter, (4) the numbers to compare against, (5) why units must match, (6) how to make them match, before the tables make sense. Reordering (e.g. converting before naming A and B) would leave the reader unable to see what the conversion is *for*.

## Paragraph Skeletons (replicable templates)

**SKELETON A — "Model intro paragraph"**

SKELETON: "One [relationship] used by [authorities] (citations) is of the form [displayed equation]. [Variable] is [quantity] in [unit], [variable] is [quantity] in [unit] and [parameters] are [status — to be found / known]."

1. **Slot 1** ("One [relationship] used by …"): a noun phrase introducing the model plus parenthetical or in-line citations; past tense not required; grammar = "One X used by Y is …".
   **Fill with different idea:** name a model from your own field (e.g. a friction law, a growth model), cite one or two sources in brackets or parentheses, keep "is of the form" as the lead-in.
   **Original:** "One equation used by scientists (Robert C. Reid, 1987) (DABIR S. VISWANATH, 2007) is of the form".
   **Demo fill:** "One relationship used by biologists (Smith, 2015) (Jones, 2018) is of the form".

2. **Slot 2** ("[displayed equation]"): a centred/displayed symbolic equation. **Fill:** place your model's algebraic form on its own line, in the same symbol style. **Demo:** "P = αNᵝ".

3. **Slot 3** ("[Variable] is [quantity] in [unit]…"): a list of variable-to-meaning-and-unit assignments, plus a final clause naming the *unknown* parameters. **Fill:** for each symbol in your equation, write "X is [physical quantity] in [unit]"; end with "and A and B are constants to be found." **Demo:** "P is population density in individuals per m², N is nutrient level in mg/L and α and β are constants to be found."

   **Fill:** swap to your specific source; restate the units of the two main variables in the order they appear in your equation.
   **Original:** "The equation found by Robert C. Reid (Robert C. Reid, 1987) and others where T is in Kelvin (K) and η is in centipoises (cP) is the following:"
   **Demo fill:** "The relationship found by Smith (Smith, 2015) where N is in mg/L and P is in individuals per m² is the following:"

2. **Slot 2** ("[displayed equation]"): the *numeric* version of your model, on its own line. **Demo:** "P = (4.1 × 10³)N⁰·⁷²".

3. **Slot 3** ("In particular the [literature] values are A = … and B = …"): an "In particular" sentence that explicitly splits out the coefficients, so the reader can later match them to a fitted curve. Grammar: "In particular the literature/source values are [param 1] = [number] and [param 2] = [number]."
   **Demo fill:** "In particular the literature values are α = 4.1 × 10³ and β = 0.72."

**SKELETON C — "Conversion-justification paragraph"**

SKELETON: "To be able to [verb], I have [action] the [source A] values and [source B] values into [unit 1] and [unit 2]. In particular, for [variable] in [old unit], its [variable] in [new unit] can be found using [formula]. [Unit A], on the other hand, is defined as [definition] whereas [Unit B] is [definition]. We know [fact 1] and [fact 2], hence [derived ratio]."

1. **Slot 1** ("To be able to …"): a purpose clause naming the *comparative* goal. Grammar: "To be able to [compare/verify/validate], I have [converted/scaled] the [literature/experimental] values and [my own] values into [unit set]."
   **Fill:** name the goal of your section; use "have converted" if your data needed unit change.
   **Demo fill:** "To be able to compare, I have converted the discrete literature values and my values into mg/L and individuals per m²."

2. **Slot 2** ("In particular, for [variable] in [old unit], …"): a one-line formula for the simpler conversion, introduced with "In particular". **Demo fill:** "In particular, for some concentration x in ppm, its value in mg/L can be found using x × density."

3. **Slot 3** ("[Unit A], on the other hand, is defined as … whereas …"): a contrast pair defining the two competing unit systems, separated by "on the other hand … whereas". **Demo fill:** "ppm, on the other hand, is defined as 1 ppm = 1 mg/kg whereas mg/L is 1 mg per 1000 mL."

4. **Slot 4** ("We know … hence …"): a derivation sentence with two known facts joined by "and", closed with "hence" and the numeric ratio. **Demo fill:** "We know 1 kg = 1000 g and 1 L = 1000 mL, hence 1 mg/L = 1 mg/kg = 1 ppm."

## Express-Idea Vocabulary

**Sequencing / structural framing**
- "is of the form" — opening line of P1; signals a model is about to be displayed.
- "the following:" — bridges a verbal lead-in to a displayed equation.
- "In particular" — twice; marks a more precise unpacking of values or of a conversion rule.

**Definition / specification**
- "is viscosity in cP" / "is the temperature in Kelvin" — assigns meaning + unit to a symbol in one clause.
- "is defined as" — formal unit definition; used for Poises.
- "whereas" — sets up a paired contrast between two unit systems (Poises vs Pascal second).

**Causal / derivation**
- "hence" — closes the unit-conversion derivation: "We know 1kg = 1000g … hence 1P as = 10gcm⁻¹ s⁻¹ = 10P."

**Purpose / justification**
- "To be able to compare" — prefaces the entire conversion block; declares *why* the work is being done.

**Evidence / authority handling**
- "(Robert C. Reid, 1987)" / "(DABIR S. VISWANATH, 2007)" — parenthetical citations attached to model claims; signals the equation is borrowed, not invented.

**Explanatory / "to be found" language**
- "are constants to be found" — flags parameters as the investigative target of the whole section.

**Result-bridging**
- "are found in the tables below" + "these values were plotted in a graph with best curves of fit" — closes the section by pointing forward to the data and curve-fit comparison.

## How to Explain an Idea (replication steps)

This section relies on the **"general form → specific instance → parameter split → unit justification → result bridge"** pattern. To explain a *new* idea the same way:

1. **Cite the source.** Open with "One [relationship] used by [authorities] (citations) is of the form …" so the reader knows the model is established.
2. **Display the general form.** Write the equation on its own line, in symbolic form, *before* any numbers.
3. **Define every symbol in one sentence.** Use "is [quantity] in [unit]" for the measured variables, and end with "and [A, B] are constants to be found" to flag the unknowns.
4. **Zoom into a specific instance.** Write "The [relationship] found by [author] (citation) where [var] is in [unit] and [var] is in [unit] is the following:" and display the *numeric* equation.
5. **Unpack the parameters.** Use an "In particular" sentence: "In particular the literature values are [A] = [number] and [B] = [number]" so each coefficient is labelled separately.
6. **Declare the comparison purpose.** Begin a new sentence with "To be able to compare, I have converted …" — name the goal before the conversion work begins.
7. **Handle the easy conversion first.** Use a separate "In particular" sentence giving the one-line formula for the simpler unit.
8. **Define the competing unit systems side by side.** Use "[Unit A], on the other hand, is defined as … whereas [Unit B] is …" so the contrast is visible before it is resolved.
9. **Derive the ratio with "hence".** Combine two known facts ("We know X and Y, hence [ratio]") to produce the numeric bridge in one sentence.
10. **Bridge to the result.** Close with "[converted values] are found in the tables below and these values were plotted … to compare coefficients [A] and [B]:" — a colon promises the next section.
