## What This Section Does (content sequence)

This is a *worked substitution* section. The ordered moves are:

1. **Universal constant definition** (R = 8.314…). Sets up the value 8.314 that recurs in the denominator.
2. **Stoichiometric substitution with in-text justification** (n = 2.00, justified by "2 electrons are transferred"). Sets up the mole-count inside the numerator.
3. **Conditional substitution with cross-reference** (Qc = 1, "Refer to section 3.3"). Sets up the equilibrium-context term.
4. **Standard-state substitution** (T = 298.15 K). Sets up the temperature in the denominator.
5. **Measured-value substitution with empirical qualifier** ("average" Ecell = 0.427 V). Sets up the last symbolic input.
6. **Final numerical verdict** (= ln(32.3) + 1.00). Closes the chain with the bare arithmetic.

The order is *universals → reaction-derived → context → environment → measurement → arithmetic*. Each move replaces one symbol with a number, shrinking the abstract equation step by step until only arithmetic remains. A student replicating this sequence with a different formula should follow the same logic: resolve constants first, then variables whose values come from the chemical system being studied, then environmental standards, then empirical measurements, and finish with the numerical form.

## How to Explain an Idea (replication steps)

This section uses a **"systematic one-symbol-at-a-time substitution into a master equation"** pattern.

1. **Open with the master equation** (or refer back to it). Every following move must visibly update it.
2. **Resolve universal constants first.** State the constant, its symbol, its numerical value, and its units in one short line.
3. **Pick the variable whose meaning is most chemistry-specific** (e.g. n, stoichiometry). Write *"Substitute the [descriptor] for [variable]"*, then give the reaction-specific reason in a second clause, then close with *"therefore, variable = value."*
4. **Move to variables whose values were derived elsewhere.** Use *"Substitute the value for [variable], variable = value (Refer to section X.Y)."* The parenthetical lets you skip re-justification.
5. **Insert standard-state values next** (T = 298.15 K, P = 101.325 kPa, etc.) in a single stem sentence without justification.
6. **Insert the measured/empirical value last,** prefixing it with *"average"* if it is a mean, so the reader knows it is experimental.
7. **After each substitution, show the equation with that one symbol replaced** (visual scaffolding on the right-hand side).
8. **End with the bare arithmetic form** (`= [numeric expression]`) so the reader sees the chain has collapsed to numbers only.

Following these eight steps on any new formula reproduces the same move-by-move logic this section uses for the Kc calculation.
