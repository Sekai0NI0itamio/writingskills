## How to Explain an Idea (replication steps)

**Pattern name:** Definition → Brevity justification → Symbolic display → Case partition → Conditional-case display.

1. **State the principle in one sentence** using "states that" followed by the operation, the result, and the condition with "as long as."
2. **Dismiss the derivation** in one sentence using "The proof is not shown as it is [brief reason]" to keep the section at the conceptual level.
3. **Show the compact symbolic form** of the claim as a displayed equation so the reader sees the notation explicitly.
4. **Announce the case split** with "could be broken down into a few cases as shown below, where [parameters]" to signal that the single rule expands into sub-cases.
5. **Display every case** as a multi-line equation block, each line equalling a result, and use "if… / …if…" to show the conditional outcomes (including the exception where the result changes).
