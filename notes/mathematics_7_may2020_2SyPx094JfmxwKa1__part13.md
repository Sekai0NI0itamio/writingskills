## Paragraph Flow (move by move)

**Paragraph 1 (single derivation block):**

1. **Carry-over verdict (resumes prior calculation).** "is traced out from an epicycle of radius 1 that rotates 4 times is 8 ∙ 1 ∙ 4 = 32." → Hands to next by **substituting the just-named quantity into a fresh calculation**: the reader now needs the same arc length re-derived another way, and the next sentence names exactly that quantity.
2. **Setup / transition.** "The arc length of the epicycle system is calculated as follows." → Hands to next by **announcing the procedure**: a colon-like promise that the next block is the worked integral, so the reader expects manipulation, not commentary.
3. **Worked calculation (single multi-line move).** "S = d/dt … dt = 8π ∫ … dt … = 32" → Hands to next by **delivering a numeric total**, which can now be compared against the figure given in move 1.
4. **Verdict via comparison.** "Both calculations produced the same arc length, so this method is verified." → Hands to next by **opening a weak spot**: an internal match is good but the reader may still distrust it, so the next sentence supplies outside evidence.
5. **External verification (authority).** "Using Wolfram Alpha, I have also checked that the result of this definite integral is correct (WolframAlpha, 2009)." → Hands to next by **completing the verification**: with internal and external checks done, the next sentence exploits the verified number rather than testing it.
6. **Implication / extension.** "With this result, we can also calculate the arc length of each curve … which is 32 ÷ 3 = 7.)" → Closes by **using the verified total as input for a new sub-result**, showing the reader the main answer feeds downstream calculations.

## What This Section Does (content sequence)

This is a **verification-by-recalculation** section. The order is:

1. **Carry the prior total forward** (so the reader knows the number to beat).
2. **Announce the new method** (one short framing sentence that names the object and signals "calculation follows").
3. **Work the calculation in full**, line by line, each line an algebraic rearrangement of the previous one (sets up an answer the reader can match against move 1).
4. **Compare the two answers** and pronounce the method verified (turns the calculation into evidence).
5. **Cite an external authority** to harden the verification (anticipates the reader's doubt about self-checking).
6. **Apply the verified result to a new sub-question** (shows the result is load-bearing for the rest of the piece).

Why this order: the section only earns trust by showing the same number comes out two ways, so the structure is *carry old answer → derive new answer → match → externalise → exploit*. A student replicating it should never put the external check before the internal one (nothing to check yet) and never apply the result before it has been verified.

## Paragraph Skeletons (replicable templates)

**SKELETON A — "Carry-over + setup" opener**
"[phrase picking up a quantity just computed] is [numerical expression] = [value]. The [quantity] of the [object] is calculated as follows."

1. *Slots:* slot 1 = a tail-of-prior-sentence fragment naming an object and a numeric substitution (noun phrase + equation); slot 2 = a stand-alone declarative announcing the procedure (present tense, ends with a period, often followed by a displayed equation).
2. *How to fill differently:* slot 1 — take the number you finished with in the previous section and write a half-sentence that restates it as "is X · Y · Z = value"; slot 2 — name the same quantity again, then write "is calculated as follows." Keep it under ten words.
3. *Original fill:* "is traced out from an epicycle of radius 1 that rotates 4 times is 8 ∙ 1 ∙ 4 = 32. The arc length of the epicycle system is calculated as follows."
4. *Demo fill (different idea):* "is generated by a sample of 200 voters at a 3:1 margin is 0.75 · 200 = 150. The margin of error of the poll is calculated as follows."

**SKELETON B — Multi-line derivation as a single paragraph**
"[Equation form] = [first manipulation] = [second manipulation] = … = [final number]"

1. *Slots:* a chain of equalities, each one an algebraic re-write of the previous line, terminating in a numeric answer; each step is set on its own centred line.
2. *How to fill differently:* start from the integral/expression named in the opener; perform one simplification per line (expand, factor, use an identity, collapse a constant); keep the rightmost expression identical to the leftmost of the next line so the chain is unbroken; end on a bare number.
3. *Original fill:* "S = d/dt … dt = 8π ∫ … dt = … = 8√2π ∫ |cos(πt)|dt = 32."
4. *Demo fill (different idea):* "V = ∫₀^L π r²(x) dx = π ∫₀^L (a − bx)² dx = π[a²L − abL² + b²L³/3] = 14.7 cm³."

**SKELETON C — "Internal match + external check + extension" closer**
"Both [method A] and [method B] produced the same [quantity], so this method is verified. Using [external tool], I have also checked that [claim] ([tool, year]). With this result, we can also [downstream calculation]."

1. *Slots:* slot 1 = a comparison clause naming two approaches and stating they agree, followed by a verification verdict; slot 2 = an external-authority sentence with citation in parentheses; slot 3 = an application sentence beginning "With this result" that re-uses the verified number in a new division/multiplication.
2. *How to fill differently:* slot 1 — name the two routes you took (hand calculation vs. integral, formula vs. simulation, etc.) and state they gave the same number; slot 2 — name the checker (Wolfram Alpha, GeoGebra, R, a textbook) and add year in parentheses; slot 3 — split the verified total by the relevant divisor and report the new quotient.
3. *Original fill:* "Both calculations produced the same arc length, so this method is verified. Using Wolfram Alpha, I have also checked that the result of this definite integral is correct (WolframAlpha, 2009). With this result, we can also calculate the arc length of each curve … which is 32 ÷ 3 = 7.)"
4. *Demo fill (different idea):* "Both the closed-form integral and the Monte Carlo simulation produced the same area, so this method is verified. Using R, I have also checked that the result of this definite integral is correct (R Core Team, 2024). With this result, we can also estimate the proportion of the disc covered by the shape, which is 14.7 ÷ 30 = 0.49."

## Express-Idea Vocabulary

- **Sequencing / setup:** "calculated as follows" (announces the worked block to come).
- **Comparison / match:** "Both calculations produced the same arc length, so this method is verified" (uses paired comparison + immediate verdict).
- **Evidence handling / authority:** "Using Wolfram Alpha, I have also checked that the result of this definite integral is correct (WolframAlpha, 2009)" (tool name + parenthetical year citation in one clause).
- **Implication / downstream re-use:** "With this result, we can also calculate the arc length of each curve" (re-uses the verified number as input).
- **Explanation verbs (carried across the section):** "is calculated as follows", "is verified", "is correct" — all passive-present declarations that turn the math into a status claim.
- **Causal hinge inside the comparison sentence:** "so" — single word that turns the equality of two numbers into a method-level conclusion.

## How to Explain an Idea (replication steps)

This section runs a **"same answer by two routes → external stamp → downstream re-use"** pattern. To replicate it on a new idea:

1. **Anchor the reader to a number they already trust** — open by carrying forward a value computed in your previous section (state it as a half-sentence so the reader remembers it).
2. **Announce the new route** in one short sentence ending with "is calculated as follows." (do not explain the method yet — show, don't tell).
3. **Display the worked derivation** as a single block of equalities; each line is one algebraic step, the right side of one line equals the left side of the next, and the block ends on a bare number.
4. **Compare the two numbers** in a sentence of the form "Both [route A] and [route B] produced the same [quantity], so this method is verified." — use "so" to convert the equality into a status claim.
5. **Cite an external checker** in a separate sentence — name the tool/software/textbook and put the year in parentheses.
6. **Apply the verified result** with a "With this result, we can also …" sentence that takes the verified total and divides/multiplies it to answer a smaller sub-question.
