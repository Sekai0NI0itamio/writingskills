This is a **continuation method/procedure block** (steps 4–9 of a larger procedure). The ordered content moves are:

1. **Finish off the previous experimental branch** (step 4 completes the like-pole cluster series). *Why first:* the reader's working memory still holds steps 1–3, so closure must come before a new branch opens.
2. **Launch a NEW experimental branch** (step 5 sets up levitation). *Why next:* once the previous branch is sealed, the procedure can pivot to a qualitatively different phenomenon.
3. **Operationally define the dependent variable** (step 6 names *levitation distance*). *Why next:* before repeating or varying, the measurand must be fixed.
5. **Add reliability through repetition** (step 7 repeats the measurement 4 more times). *Why next:* a single measurement is unstable; repetition enables averaging.
6. **Mirror the previous branch with one variable flipped** (step 8 — unlike poles, same count series). *Why next:* the only structural change is the polarity, enabling direct comparison in analysis.
7. **Lock the control variables for the whole branch** (same magnet being levitated). *Why next:* once every trial is constrained, the dataset is well-defined.
8. **Aggregate and hand off** (step 9 averages and signals analysis). *Why last:* method ends where data handling begins.
9. **Safety justification (one sentence)** — *why last:* IB method sections close with a brief safety note.

**Generalisable sequence:** *close prior branch → open new branch → define dependent variable → replicate for reliability → mirror with one flipped variable → lock controls → aggregate → safety.*

## How to Explain an Idea (replication steps)

This section uses the pattern **Procedure-with-embedded-prediction and operational-definition**, structured as *loop → branch-launch → define-variable → replicate → mirror-branch → aggregate*. To replicate for a new idea:

1. **Close the prior branch first.** Re-issue the last instruction from the previous block, but enumerate the *remaining* levels of the independent variable and lock the control variable in a separate short sentence.
2. **Announce a NEW branch explicitly.** Open with "Set up the experiment by …" and place the two interacting objects — making the *contrast* (like/unlike, hot/cold, etc.) lexically obvious.
3. **State the qualitative prediction in one sentence.** Use "There should be a [observable]." This anchors what will be measured.
4. **Operationally define the dependent variable.** Specify the *two endpoints* between which you measure (use anatomical/geometric anchors like "center of X" and "center of Z"), then label it in a single short sentence beginning "This is the …".
5. **Add reliability through repetition.** State "Drop/place/measure the same … [N] more times, and measure the same [variable]."
6. **Mirror the branch with one variable flipped.** Front the clause with "After measuring," repeat the ascending enumeration, swap only the *contrast descriptor*, then call back to the measurement steps by number ("repeat steps …").
7. **Lock the remaining controls.** Name the one item that must be identical across all trials in a "should be the same for all trials" sentence.
8. **Aggregate and hand off.** "Average all measurements, for each [unit], and begin analysis of data."
9. **Close with a one-sentence safety justification.** Use "[X] is used, so no significant [constraint]."
