## What This Section Does (content sequence)

1. **Brew the source material** (tea bags + boiling water) — establishes the liquid to be extracted; sets up the need for filtration because solids will remain.
2. **Filter the brew** — removes particulates so the liquid is clean before reagent addition; sets up the requirement for a clarified solution.
3. **Prepare the reagent** (sodium carbonate solutions of known masses) — provides the chemical agent needed for the extraction; sets up the combination step because both liquids must exist before mixing.
4. **Combine the brew and reagent** — merges the two prepared liquids as the entry point into the extraction proper; sets up the dichloromethane step that follows.

**Why this order**: each move produces a ready-to-use liquid that the next move requires. The tea must be brewed before it can be filtered; the filtrate must be clear before a reagent is added to it; the reagent must be prepared before it can be combined; both liquids must exist before they are poured together. A student replicating this with a different topic would follow: produce the target liquid → clarify it → prepare the extracting agent → combine.

## How to Explain an Idea (replication steps)

**Pattern**: *Setup → configure → time/state → clarify → prepare reagent → combine.* This is a **linear preparation chain** where each sentence produces the exact condition the next sentence requires.

1. **State the starting materials and container** — name what goes in, where, and with what medium, giving quantities and tolerances.
2. **Describe the apparatus configuration and its purpose** — specify the equipment surrounding the mixture and state why it is arranged that way (a "to [purpose]" clause).
3. **Give the duration and the end-state** — name how long the process runs and what condition the mixture reaches before the next step.
4. **Name the removal or clarification action** — state what is taken away or filtered and why, so the liquid is ready for the next reagent.
5. **Introduce the reagent and its delivery tool** — state what is added, how much, and with what instrument.
6. **Detail the reagent's own preparation** — list the masses or volumes measured, the tool used, the vessel, the solvent, and the mixing action.
7. **Combine the prepared liquids** — state that the two solutions are poured together, naming both and the receiving vessel.
