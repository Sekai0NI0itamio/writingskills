**Paragraph 1** (5 sentences)

1. **Claim / roadmap** — *"There are two components to quaternion"* — Announces the dual structure that the rest of the paragraph will unpack; hands off to sentence 2 by demanding enumeration of the two items.
2. **First-component declaration** — *"Firstly, a rotation axis needs"* — Delivers the first of the two promised components; hands off by the pronoun "This" pointing to the just-named axis, inviting a definition.

4. **Second-component declaration (parallel mirror)** — *"Then, an angle describing the magnitude"* — Delivers the second component using the mirrored syntax of sentence 2; hands off by again introducing "this" — the angle — which the next sentence must resolve visually.

## What This Section Does (content sequence)

This is a **scaffolding-by-enumeration** section. The moves, in order:

1. **Announce the count of parts** ("two components…") — sets up the reader's expectation of a complete pairing.
2. **Name part 1** ("axis needs to be defined") — fills the first slot.
3. **Define part 1** ("unit vector representing the direction") — gives the reader the math vocabulary to recognise it later.
4. **Name part 2** ("angle describing the magnitude") — fills the parallel slot.
5. **Cite visual evidence** ("shown in figure") — anchors abstract terms in a concrete image.
6. **Apply the abstraction to the specific case** ("due to both the angles being π/2… this is the rotation angle") — bridges definition to the project at hand.
7. **State the personal method** ("I found the axis graphically") — pivots from definition to the student's own work.
8. **Justify the count of cases** ("since… on the X and Y axes… four possible direction vectors") — explains why the upcoming list has the length it has.
9. **Display the list** — delivers the concrete output.

The order works because each move supplies the referent the next move needs: count → names → definitions → visual → specific instance → method → reasoning behind count → items.

## Paragraph Skeletons (replicable templates)

**SKELETON A — Two-component enumeration paragraph**

`"[Concept] has two components. Firstly, a [first component] needs to be defined. This is a [definition of first component]. Then, a [second component] [verb-phrase describing it] needs to be defined. This is shown in [figure reference]."`

1. **Slot meanings & grammatical shape:**
   - Slot 1 — Concept name (noun phrase) + cardinal number ("two").
   - Slot 2 — First component (noun), introduced with *"Firstly"*.
   - Slot 3 — Tight mathematical definition of slot 2, introduced with *"This is a…"*.
   - Slot 4 — Second component (noun) + participle clause describing its role, introduced with *"Then"*.
   - Slot 5 — Figure reference, introduced with *"This is shown in…"*.
2. **How to fill with a different idea:** Pick any mathematical object that is built from exactly two pieces (e.g., a complex number = real + imaginary; a line = point + direction; a 2D transformation = scale + rotation). Slot 1: name it. Slot 2: name part A. Slot 3: define part A in one clause. Slot 4: name part B with a "-ing" verb describing what it quantifies. Slot 5: refer to a self-drawn diagram.
3. **Original fill:** *"There are two components to quaternion rotations. Firstly, a rotation axis needs to be defined. This is a unit vector representing the direction of the rotation axis. Then, an angle describing the magnitude of the rotation about the axis needs to be defined. This is shown in figure 6."*
4. **Demonstration fill (different idea, same rhythm):** *"A 2D affine transformation has two components. Firstly, a linear map needs to be defined. This is a 2×2 matrix encoding how the basis vectors stretch and shear. Then, a translation vector shifting the origin needs to be defined. This is shown in figure 2."*

**SKELETON B — Application + personal-method + enumeration paragraph**

`"Due to [specific values] being [unit], this is also the [term]. I [past-tense verb] the [quantity] [method]. Since [constraint on the setup], I [past-tense verb] the [number] possible [items]. These are: [list]."`

1. **Slot meanings & grammatical shape:**
   - Slot 1 — Causal clause (cause + consequence) that ties the prior figure to a named quantity.
   - Slot 2 — First-person past-tense declaration of procedure, one short clause.
   - Slot 3 — "Since…" justification explaining why the count of items is what it is.
   - Slot 4 — Cardinal number + noun phrase the reader expects to see listed.
   - Slot 5 — Colon-leading list.
2. **How to fill with a different idea:** Choose a specific numerical case of a previously defined mathematical object. Slot 1: state the numerical coincidence that lets you name the quantity. Slot 2: declare the method in two or three words ("graphically", "by inspection", "via symmetry"). Slot 3: name the axis/dimension/constraint that fixes how many cases arise. Slot 4: state the count and item type. Slot 5: list them.
3. **Original fill:** *"Due to both the angles being π/2 radians, this is also the rotation angle. I found the axis graphically. Since the rotations are done on the X and Y axes, I found the four possible direction vectors. These are: ~a, ~b, ~c, ~d."*
4. **Demonstration fill (different idea, same rhythm):** *"Due to both intercepts being equal, this is also the line of symmetry. I found the gradient by inspection. Since the triangle is isosceles on the horizontal axis, I identified the two possible mirror lines. These are: y = x and y = −x."*

## How to Explain an Idea (replication steps)

This section uses a **"promise-pair → define-pair → visual-anchor → apply-to-case → declare-method → justify-count → list"** pattern. To explain a new idea with the same pattern:

1. **Promise the count.** Open with "[Topic] has N components" so the reader knows the paragraph's job is to deliver exactly that many pieces.
2. **Name component 1** with "Firstly, a [term] needs to be defined."
3. **Define component 1** in one tight clause using "This is a [category] [participle phrase]."
4. **Name component 2** using the mirrored "Then, a [term] [participle phrase] needs to be defined."
5. **Point to a figure** with "This is shown in figure X" to relocate the reader's attention to a self-drawn diagram.
6. **Apply the definition to your specific case.** Use "Due to [specific numerical/situational fact], this is also the [term]" to bridge the general definition and the project-specific instance.
7. **State your method in one short clause**, first-person past tense ("I found the …").
8. **Justify the count of items** with "Since [constraint], I found the [number] possible [items]."
9. **Launch the list** with "These are:" and display the enumerated objects directly underneath.

The rhythm depends on step 1 being delivered before the reader has any detail (so the pair feels like a promise), steps 2–4 being syntactically mirrored (so the pair feels complete), and step 6 landing the abstract terms onto the specific numbers of *this* exploration before the student's own work begins.
