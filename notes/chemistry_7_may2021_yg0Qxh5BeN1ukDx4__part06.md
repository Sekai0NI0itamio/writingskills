## What This Section Does (content sequence)

This is a **pure method/procedure** section. The ordered content moves are:

1. **System assembly (materials + volumes)** — sets up the reaction vessel with specified quantities.
2. **Closure and homogenisation** — seals the system and dissolves reagents so the reaction can actually occur.
3. **Initiation of the reaction** — applies the energy source for a stated duration; produces the analyte.
4. **Sampling (aliquot transfer)** — moves from bulk product to a measurable quantity, opening an analysis vessel.
5. **Reagent addition that converts analyte to titratable species** — iodide converts hypochlorite to iodine; this is the bridge between electrolysis and titration.
6. **Titration (quantification)** — measures the iodine indirectly.
7. **End-point criterion (colour change specification)** — defines when the measurement is complete.
8. **Figure caption for apparatus verification.**

The sequence works because each step **produces the physical state the next step requires**: bulk solution → sealed & mixed → reacted → aliquoted → chemically converted → titrated → colour-cued → visually confirmed. Another student could replicate the order for any indirect-iodometric determination by following: *vessel prep → energise → aliquot → convert analyte into a titratable form → titrate → specify end-point → photograph apparatus.*

## Express-Idea Vocabulary

- **Sequencing (implicit, via numbering):** "1." / "2." / "3." — the *numbering itself* is the connective; every step's logical place in the procedure is its only justification.
- **Specification / quantification:** "330mL of water", "Four 25mL samples", "0.05M potassium iodide", "0.005M sodium thiosulphate" — precision carries the logic: numbers match so reactions are stoichiometric.
- **Cause-consequence (implicit, no explicit "therefore"):** "the desired amount of salt was added" → "shaken well to **dissolve** the salt" — the verb "to dissolve" names the causal purpose of the shaking.
- **Temporal / stage-marker:** "During the last stage of titration, when the solution is pale yellow" — locates the reader inside the procedure at the correct moment.
- **Criterion / definition verbs:** "The end-point is **reached** when" — uses a passive definitional construction to lock the reader onto a single observable change.
- **Evidence handling / visual reference:** "(a) Titration setup with iodine solution (b) Electrolysis in progress" — figure label uses parallel noun phrases to bind image to procedure.
- **No contrast, no concession, no "however/therefore" connectives appear** — the section relies entirely on the numbering and on verbs of action ("filled", "sealed", "shaken", "switched", "extracted", "transferred", "added", "titrated", "reached").

## How to Explain an Idea (replication steps)

The pattern is: **chronological action chain + embedded criterion sentence** (no theory, no comparison, no commentary). To replicate:

1. **Open with the bulk system**: state the vessel, the bulk solvent volume, and the solute that will be consumed or generated (past passive, one number).
2. **Close and homogenise**: name how the vessel is sealed and how the contents are mixed, explicitly linking the action to a purpose verb ("to dissolve", "to equilibrate").
3. **Initiate the process**: name the energy/source and a duration placeholder, so the reader knows the reaction window.
4. **Sample into an analysis vessel**: specify count × aliquot volume → receiving vessel (numbers must match the next step 1:1).
5. **Add the converting reagent**: specify volume + concentration; this is the chemical bridge between the reaction and the titration.
6. **Titrate**: specify titrant + concentration (smaller than the converting reagent, signalling a small-scale quantification).
7. **Insert a single criterion sentence**: use "when the solution is [intermediate colour]" to set a temporal cue, name the indicator with drops + %, then close with "The end-point is reached when the solution turns from [colour A] to [colour B]."
8. **Anchor with a figure caption**: parallel (a)/(b) labels naming the apparatus already described, so the reader can verify visually.

The mechanism of clarity is **state → action → new state → action**: every sentence leaves the system in a condition the next sentence can act upon, and the embedded colour-criterion sentence converts the procedure from "do these things" into "do these things *until this happens*."
