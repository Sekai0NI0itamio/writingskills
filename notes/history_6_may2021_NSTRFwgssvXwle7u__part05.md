## What This Section Does (content sequence)

1. **Alphabetized source list** — Orders all cited works by author surname (Conroy → Young) so readers locate any reference in O(1) time; sets up uniform formatting expectation.  
2. **Full bibliographic description per entry** — Each entry supplies author, title, container, publication metadata, and access locator (DOI/URL/database) in a fixed sequence; this completeness lets a reader retrieve the exact edition.  
3. **Format discrimination by source type** — Journal articles include volume/issue/pages/DOI; books include edition/publisher/year; periodical issues include issue range/page; digital books add stable URL — the template adapts to material form while keeping field order constant.  
4. **Chronological spread signaling** — Dates range 1930–2009, implicitly showing historiographical depth; the ordering by author (not date) keeps retrieval primary, historiography secondary.  
5. **Page-numbered closure** — Final page markers "10" and "11" anchor the bibliography physically in the document; signals end of reference apparatus.

## Paragraph Skeletons (replicable templates)

### SKELETON A: Journal article with DOI/database  
**Slots:**  
1. **Author** — Surname, Given. (noun phrase)  
2. **Article title** — "Title in sentence case." (quoted string)  
3. **Journal title** — *Italicized Journal Name*, (italic noun phrase)  
4. **Volume/issue** — vol. X, no. Y, (prepositional phrase)  
5. **Publisher/association** — [Publisher, Association], (bracketed noun phrase)  
6. **Year & pages** — YYYY, pp. N–M. (temporal + locative)  
7. **DOI/database** — doi:XXXX. Database. (identifier + repository)  

**Fill instructions:**  
- Slot 1: Write the author's surname, comma, first name/initials, period.  
- Slot 2: Copy the exact article title in quotation marks, sentence case, period inside quotes.  
- Slot 3: Italicize the journal title, add comma.  
- Slot 4: Write "vol." + number, comma, "no." + number, comma.  
- Slot 5: In square brackets, list publisher then association, comma.  
- Slot 6: Year, comma, "pp." + page range, period.  
- Slot 7: "doi:" + number, period, database name, period.  

**Original (Conroy):**  
Conroy, Hilary. "Japanese Nationalism and Expansionism." *The American Historical Review*, vol. 60, no. 4, [Oxford University Press, American Historical Association], 1955, pp. 818–29, doi:10.2307/1844921. JSTOR.  

**Demo fill (different topic):**  
Patel, Raj. "Monsoon Variability and Rice Yields in Bengal, 1890–1940." *Journal of Asian Environmental History*, vol. 12, no. 3, [Cambridge University Press, Association for Environmental History], 2021, pp. 45–72, doi:10.1017/jaeh.2021.4. Project MUSE.

### SKELETON B: Monograph (book) with edition  
**Slots:**  
1. **Author** — Surname, Given.  
2. **Book title** — *Italicized Title: Subtitle*.  
3. **Edition** — Nth ed.,  
4. **Publisher** — Publisher Name,  
5. **Year** — YYYY.  

**Fill instructions:**  
- Slot 1: Author surname, comma, given name, period.  
- Slot 2: Full book title in italics, colon for subtitle, period.  
- Slot 3: Edition ordinal + "ed.", comma (omit if first edition not stated).  
- Slot 4: Publisher name, comma.  
- Slot 5: Four-digit year, period.  

**Original (Ishii):**  
Ishii, Ryouchi. *Population Pressure and Economic Life in Japan*. 1st ed., University of Chicago Press, 1937.  

**Demo fill:**  
Chen, Wei-Ling. *Urban Water Infrastructure in Republican Shanghai*. 2nd ed., Harvard University Asia Center, 2018.

## How to Explain an Idea (replication steps)

**Pattern:** *Standardized bibliographic entry template → field-by-field population → alphabetical sequencing → physical pagination*

**Steps to build a new bibliography with this logic:**  
1. **Collect every cited source** — gather author, exact title, container, publication facts, locators (pages/DOI/URL).  
2. **Classify each source by type** — journal article, book, edited volume chapter, periodical issue, digitized book, etc.  
3. **Select the matching skeleton** (A, B, C, D or create new for new types) — each type has a fixed field order.  
4. **Populate every slot** — copy data verbatim from the source; preserve capitalization, punctuation, italics/quotes conventions.  
5. **Alphabetize entries by author surname** — letter-by-letter; ignore particles (van, de) per style guide.  
6. **Apply hanging indent & double-spacing** — visual rhythm matches the sample.  
7. **Add page numbers** — place "10", "11" (or continuing) at bottom right of each bibliography page.  
8. **Verify cross-referencability** — every in-text citation must find its entry; every entry must have been cited.
