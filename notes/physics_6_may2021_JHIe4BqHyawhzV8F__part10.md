## What This Section Does (content sequence)

This section type is a **derivation + worked-example + scope statement**. The ordered content moves are:

1. **Cite authority** for the underlying physics concept. *Why first:* establishes that equating forces is a sanctioned operation.
2. **State the target variable explicitly** ("solve for μd"). *Why second:* tells the reader the destination of the algebra before the algebra starts.
3. **Write the equated equations in raw form**, then **progressively simplify** across several lines (move terms, factor, divide). *Why this order:* mirrors how a reader can re-derive it — one operation per line is auditable.
4. **Identify the obstruction** (acceleration is not directly measured) → **introduce a substitution identity** (kinematic equation) → **define every variable** in the identity → **solve for the substitution term**. *Why this order:* the reader must be told *why* a new formula is needed before being shown *which* one, and must know *what each symbol means* before *isolating it*.
5. **Show a fully worked numerical example** with real-looking values, written in the same layout as the symbolic version so the reader sees symbol↔number mapping.
6. **Close with a scope statement** explaining how the new closed-form equation will be applied across the dataset (Table 1). *Why last:* confirms that the algebra now produces the dependent variable of the investigation.

The pattern is: **warrant → target → algebraic isolation → substitution with definitions → numerical demonstration → application.**

## How to Explain an Idea (replication steps)

This section uses the pattern: **authority-warrant → target variable → algebraic isolation line-by-line → substitution-via-defined-identity → worked numerical demonstration → application scope.**

Numbered replication steps:

1. **Anchor the operation in a source.** Open with a citation to a textbook or website that legitimises the physics concept (e.g. "Determining the Net Force — The Physics Classroom"). This is the warrant.
2. **Name the target variable explicitly.** Write "solve for [symbol]" before any algebra starts so the reader knows the destination.
3. **Write the equated expressions on one line.** Use display-style equations, no prose. Show both sides of the equals sign in full.
4. **Manipulate one operation per line.** Move one term across the equals sign, then divide by a common factor, then factor — each line produces a new equation. Do not combine two operations on one line.
5. **Identify the variable that cannot be measured directly** (here: acceleration) and announce the substitution purpose with "in order to substitute [old] with [new]". Insert the modelling assumption as a parenthetical "it is assumed …".
6. **Recall the substitution identity** (e.g. v² = u² + 2aΔs) and immediately follow with a "Where:" glossary defining every variable in it, including any "which is equal to 0 since…" justification for boundary values.
7. **Isolate the substitution variable** on the left of its own line and tag with an equation number in brackets.
8. **Plug the substitution back into the isolated target equation** and tag with a new equation number.
9. **Demonstrate with a worked example.** Write "Example:", then rewrite the final equation with all symbols replaced by decimals, keep the layout parallel to the symbolic form, perform arithmetic one operation per line, and end with "[target] = [number]".
10. **Close with a scope sentence.** State which dataset or table the closed-form equation will now be applied to, in past passive ("… was used to generate the values of … per each [independent variable] value").
