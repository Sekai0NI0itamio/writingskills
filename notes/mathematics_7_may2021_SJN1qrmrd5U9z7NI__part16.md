## What This Section Does (content sequence)

For an *appendix-of-raw-calculations* section, the sequence is:

1. **Section type label first** ("Appendix 3") — sets the reader's expectations away from argument and toward reference.
2. **Operation type second** ("Percentage Error Calculations") — fixes the meaning of every subsequent column without restating the formula.
3. **Source-equation reference third** ("for Equation 1") — anchors the calculation to a formula already defined earlier in the paper.
4. **Ordered tabular evidence fourth** (rows sorted by the primary variable) — so the reader can see how the dependent columns respond to a changing input.
5. **Repetition of identical column slots across rows** — visually asserts procedural consistency.

A student replicating this order should: **label → operation → equation anchor → ordered evidence → repeated structure**. The ordering matters because the label/operation/anchor trio in steps 1–3 is what licenses the reader to interpret the table without re-reading the body; without that trio the table is unreadable.

## How to Explain an Idea (replication steps)

This section uses the **label → scope-anchor → ordered raw evidence** pattern, NOT a definition→unpack→example→implication explanation. It is a reference/evidence appendix, not an explanatory paragraph. To replicate it for a new idea:

1. **Choose a section-type noun** that already exists in your paper (Appendix, Table, Figure) and number it.
2. **Name the operation in noun form** (e.g. "Uncertainty Propagation", "Linearisation Calculations", "Degrees-of-Freedom Count").
3. **Anchor the operation to one specific reference** using "for [Equation X]" or "for [Variable Y]" so the reader does not have to hunt for which formula you used.
4. **Order the rows by the input/independent variable** so the dependent columns visibly respond to a single changing input.
5. **Within each row, list the dependent columns in the order the calculation is performed** so left-to-right reading mirrors the worked procedure.
6. **Keep the column template identical across every row** — the repetition is itself the proof of procedural consistency.

Steps 1–3 supply the *frame*; steps 4–6 supply the *evidence*. Skipping steps 1–3 makes the table uninterpretable; skipping steps 4–6 makes the table look like raw dumps rather than a worked calculation.
