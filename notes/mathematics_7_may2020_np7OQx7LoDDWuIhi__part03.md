## What This Section Does (content sequence)

This is a **worked-solution section that instantiates a general model with empirical data**. The moves, in order:

1. **State procedural purpose** — anchor the reader on which variable the next block targets. *Why first:* it justifies everything that follows and prevents the algebra from looking arbitrary.
2. **Reference the source figure** — point back to where the numerical evidence lives. *Why next:* the reader must know where the numbers are coming from before seeing them.
3. **Extract the data** — list intercepts/coordinates in exact form. *Why next:* the substitution step below is meaningless without concrete values.
4. **Substitute into the general equation** — invoke the general model by number and perform the insertion. *Why next:* it converts the abstract model into a solvable system.
5. **Display the resulting system of equations** — let the algebra become visible. *Why next:* the next move (an operation) refers back to specific equation labels.
6. **Name the elimination operation** — state which equations are combined and how. *Why next:* the reader needs to see the reasoning before the worked line.
7. **Show the worked line and the resulting variable** — display the algebra and conclude with the solved letter. *Why next:* this unlocks back-substitution.
8. **Back-substitute into the remaining equations** — feed the solved value in, naming the source equation each time. *Why next:* the general model is now fully numeric.
9. **Restate the fully-instantiated model** — declare the final equation as the conclusion. *Why next:* it is the section's deliverable.
10. **Hand off to visual verification** — point to the figure that confirms the model. *Why last:* it closes the loop by returning to the empirical shape.

## Express-Idea Vocabulary

**Sequencing / back-reference**
- *"Looking back at Figure 2, we can see that"* — backward look to earlier evidence.
- *"Substituting this value back into (4) or (5)"* — backward operational re-use of a known value.

**Method / operation verbs**
- *"Substituting these values into (3)"* — insertion into a general model.
- *"We can subtract (5) from (4)"* — declared algebraic elimination.
- *"Substituting this value back into (4) or (5) gives us"* — back-substitution verb phrase.

**Result / consequence markers**
- *"∴"* (in *"∴𝑐 = 1"*) — symbolic "therefore / hence" before a solved value.
- *"Therefore, according to this model"* — verbal consequence marker that opens the final restatement.

**Specification / source-naming**
- *"into (4) or (5)"* — disjunction that tells the reader which equations are interchangeable here.
- *"from (6), 𝑎 = 4.41"* — prepositional phrase that pins a result to the one equation that contains it.

**Evidence handling**
- *"we can see that"* — softens a numerical extraction as visual observation.
- *"As can be seen from Figure 4, the"* — visual-verification cue for the next move.

**Model-restatement verb**
- *"can be quoted as"* — announces that a final equation is about to be displayed.

## How to Explain an Idea (replication steps)

**Pattern name:** *Reference → Extract → Substitute → Eliminate → Back-substitute → Restate → Verify.* This is the *general-model-instantiated-by-data* explanation pattern.

**Replication steps for a new idea:**

1. **Anchor the procedural goal.** Open with a hanging clause that names the variable the next block will isolate (slot must state *which* letter is being targeted).
2. **Point back to a figure.** Use *"Looking back at Figure X, we can see that …"* so the reader knows the data is empirical, not assumed.
3. **Extract coordinates/values precisely.** List the intercepts (or equivalent data points) in coordinate form, joined by *"and"*.
4. **Announce the substitution.** Write *"Substituting these values into (general equation number) yields …"* so the reader sees the link between data and model.
5. **Display the resulting system.** Let the equations appear, each with a label.
6. **Declare the elimination operation.** Choose two labelled equations that share a term and state the operation explicitly: *"We can subtract (A) from (B) to give us …"*.
7. **Show the worked line and the solved variable.** Use a centred equation followed by *"∴ [var] = [value]"*.
8. **Back-substitute, naming the source.** For each remaining unknown, write *"Substituting this value back into (A) or (B) gives us [var] = [value]; and from (C), [var2] = [value2]"*.
9. **Restate the fully-instantiated model.** Use *"Therefore, according to this model, … can be quoted as:"* immediately before the final equation.
10. **Hand off to visual verification.** Close with *"As can be seen from Figure Y, …"* so the next paragraph can compare the derived equation to the original object.
