## What This Section Does (content sequence)

The ordered moves of a reference list section:

1. **Author identifier** (surname, first name / initial) — establishes WHO, enabling alphabetical lookup.
2. **Co-author tag** ("et al." or full list) — distributes scholarly credit.
3. **Work title** (in quotation marks for articles, italics for books/journals) — names WHAT.
4. **Venue** (journal, publisher, website) — locates WHERE the work lives.
5. **Identifying numbers** (vol., no., pp., edition) — narrows to WHICH portion.
6. **Date** (month/year) — situates WHEN.
7. **Retrieval handle** (DOI or URL) — provides HOW to access permanently.

**WHY this order**: each successive field narrows the reader's search progressively — person → work → container → slice → time → permanent link. Replicate this funnel for any topic.

## Express-Idea Vocabulary

This section is a bibliography, so traditional connective vocabulary is largely absent. The "vocabulary" that moves logic forward is **citation-structuring vocabulary**:

- **Identification marker**: `"et al."` — used in `"Bernstein, Pierre, et al."` and `"Valle, Rodrigo, et al."` — abbreviates multiple authors while preserving lead-author credit.
- **Volume/issue marker**: `"vol. [X], no. [Y]"` — used in `"vol. 29, no. 5, 18 Feb. 2019"` — narrows source from journal to specific issue.
- **Page-range marker**: `"pp. [A]–[B]"` — used in `"pp. 4038–4041."` — locates the precise article slice.
- **Permanent identifier**: `"doi:10.1109/tasc.2019.2899950"` — used in every IEEE entry — provides machine-resolvable retrieval.
- **Source-type marker**: italics vs. quotation marks around titles distinguish journal articles (`"Article."`) from journal names (`IEEE Transactions…`) and books (`Oxford IB Physics Textbook`).
- **No-author rule**: title-led entry `"10th Class Science Magnetic Effects…"` and `"Faraday Disc 2.0…"` — places these in alphabetical order by first significant title word.
- **Edition marker**: `"2014 Edition"` — used in `"Oxford IB Physics Textbook 2014 Edition"` — disambiguates from other printings.

## How to Explain an Idea (replication steps)

This section follows the **identification-funnel pattern**: person → work → container → slice → time → retrieval handle. Although bibliographies don't "explain" an idea in the prose sense, this is the meta-pattern used to make sources retrievable.

To reproduce this pattern for ANY new topic:

1. **Identify the author** — surname first, followed by first initial; alphabetise multiple entries by this surname.
2. **Add co-authors** — list up to two fully, then add "et al." for three or more.
3. **Name the work** — put article titles in quotation marks; italicise book and journal names.
4. **Locate the work** — give journal name + publisher + website as appropriate.
5. **Add identifying numbers** — include volume, issue, page range, or edition in that order.
6. **Insert date** — month + year (or just year for books).
7. **Provide retrieval handle** — close with a DOI for academic articles or a full URL for online sources.
8. **Enforce one ordering rule** — alphabetical-by-surname across the whole list; never mix ordering conventions.
9. **Maintain format consistency** — every entry uses identical punctuation (periods, commas, italics placement).
