## What This Section Does (content sequence)

For an IB Investigation references list, the ordered moves are:

1. **Primary peer-reviewed research** (Babalola 2019; Das et al. 2011) — first, because it anchors the experiment's quantitative claim in published primary data.
2. **Course textbook** (Brown & Ford 2014) — second, because it provides the underlying theory the IA is built on.
3. **Methods/uncertainty authority** (Farrance & Frenkel 2012) — third, because it legitimises the error-handling calculations.
4. **Computational/technical tool** (Desmos n.d.) — fourth, because it names the instrument used to process data.
5. **Background web explainers** (OpenStax 2016; Wasserman n.d.) — last, because they supply accessible definitions of underlying concepts.

The order is set by *what each source will be used to justify* in the body: experimental result → theory → method → instrument → background concept. A student replicating this should place each source in the slot where its authority will first be invoked in the write-up.

## Paragraph Skeletons (replicable templates)

**SKELETON A — Peer-reviewed journal article**
`"Author, A. (Year). Article title. Journal Name, Volume(Issue), pgs. X–Y. doi:..."`

Slots:
1. Surname-comma-initial (or chained co-authors with "and").
2. Four-digit year in parentheses.
3. Sentence-case article title.
4. Italicised journal name.
5. Volume(Issue) in numerics.
6. `pgs. X–Y` page range.
7. `doi:` string.

Original fill: "Das, K., Sahoo, P., Sai Baba, M. and Swaminathan, P. (2011). Kinetic Studies on Saponification of Ethyl Acetate Using an Innovative Conductivity-Monitoring Instrument with a Pulsating Sensor. International Journal of Chemical Kinetics. 43(19), pgs. 648–656."

`"Author1, A. and Author2, B. (Year). Book Title. Ned. Place: Publisher."`

Slots:
1. Two-or-more authors joined by "and", surname-comma-initial.
2. Year.
3. Italicised book title.
4. Edition (`2nd ed.`, `3rd ed.`).
5. City of publication.
6. Publisher name.

## Express-Idea Vocabulary

This section uses **structural punctuation and field-marker phrases** in place of argumentative connectives. Grouped by job:

**Source-type markers (specification):**
- "International Journal of Chemical Kinetics. 43(19)" — tags peer-reviewed journal.
- "Pearson Higher Level Chemistry. 2nd ed." — tags textbook with edition.
- "Available at:" — tags a retrievable web source.

**Authority / evidence handling:**
- "(2011)", "(2014)", "(2019)" — year-stamps the source.
- "(n.d.)" — marks undated online content.
- "doi:10.5251/ajsir.2015.6.1.1.4" — persistent identifier pinning the citation to the original.
- "Accessed: 3 April 2020" — verifies retrieval and guards against link rot.

**Internal sequencing (within an entry):**
- "and" — joins co-authors: "Brown, C. and Ford, M."
- "pgs. 648–656" — page-range en-dash marks extent.

**Categories ABSENT:** no causal ("therefore", "hence"), no concessive ("however", "although"), no comparative ("whereas", "in contrast"), no sequential ("firstly", "subsequently"). The section's logic is positional/alphabetical, not argumentative.

## How to Explain an Idea (replication steps)

The pattern this section embodies is **Authority → Date → Title → Container → Location → Verification**. It is a citation-justification pattern; it tells the reader *why a claim is trustworthy* and *where to retrieve it*. Step-by-step replication for any source:

1. **Name the authority** in surname-comma-initial format (or institutional name). Slot: proper noun.
2. **Stamp the year** in parentheses, or use `(n.d.)` for undated online material.
3. **State the title of the specific work** (article title, book title, or quoted page title).
4. **Name the container** — journal name + volume(issue), book edition, or website name.
5. **Provide a location** — page range, DOI string, or full URL.
6. **For web sources, append the access date** as `Accessed: D Month YYYY`.

The same six-slot template repeats for every entry; only the fillers change. Mirror it in the body of the IA as **Authority → Claim → Evidence → Method** whenever you paraphrase a source, so the reader can trace each borrowed idea back to its origin.
