## What This Section Does (content sequence)
A short "extension-and-display" subsection of a mathematical exploration. The ordered moves are:
1. **Operationalize the prior result** — show the formula works by plugging in a sample value (sets up "we have a working tool").
2. **Announce a further generalization** — open the door to extending a parameter (sets up "what if we change X?").
3. **State the proposal with a hedge** — propose the concrete extension (3 sets instead of 2) (sets up "here is the new structure").
4. **Predict the geometric consequence** — name the pattern the extension produces (sets up "here is what you should picture").
5. **Hand to the figure** — let the reader see the geometry (sets up decoding).
6. **Decode the figure with colour coding** — translate visual elements into variables (sets up convention fixes).
7. **Clarify remaining conventions** — explain dashed vs solid (closes the visual interpretation).

WHY this order: each move exposes what the next one needs. You cannot generalize before you have a working tool; you cannot propose a specific change without announcing you are generalizing; you cannot name the pattern without having stated the change; you cannot decode the figure without first pointing at it; and you cannot end the figure's explanation while a convention is still ambiguous.

## How to Explain an Idea (replication steps)
The pattern is **tool-validation → parameter-extension → consequence → visual anchor → visual decoding → convention cleanup**.

To replicate it for a NEW idea:
1. **State that you are now using the prior result on a concrete input.** Plug a representative value into your derived expression and name the output you obtain; reference the simpler case it mirrors.
2. **Open the door to a wider case.** Use a modal-hedged sentence ("We can think to even further generalize…") to signal scope is about to expand.
3. **Make the extension concrete and hedged.** State the specific structural change ("Perhaps we could consider including…") using "Perhaps" or "could" so the leap feels exploratory, not asserted.
4. **Predict the qualitative consequence.** Use "This would result in…" to convert the parameter change into a named geometric/structural pattern.
5. **Hand to a figure.** Close with a colon and "a visualization can be drawn as such:" — the figure is now the next sentence.
6. **Decode the figure element-by-element.** Use "as we can see in Figure N that we have the '…' variation" and pair each visual feature with a colour.
7. **Close the legend.** Clarify any leftover visual convention (dashed vs solid, arrow style, etc.) so nothing in the figure is left ambiguous.
