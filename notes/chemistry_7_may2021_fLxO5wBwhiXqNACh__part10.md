## What This Section Does (content sequence)

This section is a **Quantitative Results** presentation. It makes these moves in order:

1. **Identify the substance and measurement type** — "Na2CO3" and the column schema establish what is being measured and why (the titration volumes are the core data). This sets up the frame for everything that follows.

2. **Define the uncertainty framework** — The ± values ("±0.05mL", "±0.1mL") are stated before the data rows, so the reader knows the precision of each measurement type before seeing the numbers. This orders the reader to interpret data with appropriate caution.

3. **Present replicated trial data** — Five titre rows are listed sequentially, each with initial reading, final reading, and volume. This builds an empirical base; the repetition sets up the reader to expect an average.

4. **Compute the average and random uncertainty** — The "Avg." and "Random △ Avg." columns synthesise the five trials into a representative value and its spread. This moves the reader from raw data to summary statistics.

5. **Defer detailed calculations** — The note directs the reader to the 'Calculations and Data Processing' section for derivation. This keeps the results section clean while promising methodological transparency.

6. **Transition to the next section type** — "B. Qualitative" signals a shift from numbers to description. This closes the quantitative mode and opens the qualitative mode.

**Generalisable sequence for any student**: Name the substance/variable → define measurement columns and their uncertainties → present replicated trials → compute mean and spread → defer derivations to a calculations section → transition to the next analytical mode.

## How to Explain an Idea (replication steps)

**Pattern used**: *Organise → Present trials → Summarise → Note uncertainty → Defer derivation → Transition.*

To explain a NEW idea (e.g., a different experiment's results) with the same pattern, follow these steps:

1. **Name the substance or variable** — State what you measured in one phrase (e.g., "Copper sulfate solutions").
2. **Define the table columns and their uncertainties** — List each trial label, the measurement type (initial/final/calculated), and the ± uncertainty for each column type before presenting any numbers.
3. **Present each trial as a row** — For every replicate, give the initial reading, final reading, and calculated volume (or equivalent), in the same order for all trials.
4. **Add summary columns** — Compute the average across all trials and add a column showing each trial's deviation from that average.
5. **Add a deferral note** — Write a sentence stating that the detailed calculation method for the uncertainty will appear in a separate section, naming that section explicitly.
6. **Transition to the next section** — Label the next analytical mode (e.g., "C. Observations") to signal the shift from numerical results to the next type of evidence.
