## What This Section Does (content sequence)

This is an **appendices** section, so its job is *reproducibility audit-trail*, not argumentation. The ordered moves are:

1. **Participant-facing materials in chronological research order** (instructions → consent → debrief) — so an ethics reviewer can trace what every participant encountered before, during, and after.
2. **Stimulus with a retrievable source** — so the IV can be replicated by a future reader.
3. **Measurement instruments in paired order** — so the reader sees that each condition had its own tool, not a shared one.
4. **Raw data with a caption, condition labels, notation key, and unit-conversion note** — so the numbers can be decoded before being summarised.
5. **Descriptive operators (mean, SD) applied group-by-group with significant-figure flags** — so the reader can verify the central tendency and spread for each IV level.
6. **Inferential test identification with exclusion notes** — so the reader knows which statistical model was chosen and why some cases were removed before ranking.

The order is **research-process chronological at the top, then statistical-pipeline ascending at the bottom** (raw → descriptive → inferential). The first block sets up *what was done to participants*; the second block sets up *how the resulting numbers were crunched*. A student replicating the sequence with a different topic would: list participant materials in order of administration, supply stimulus sources, pair condition-specific measurement tools, then show data tables followed by an operator-by-operator analytic walkthrough.

## How to Explain an Idea (replication steps)

The pattern this section uses is **audit-trail display: identify → supply → specify → flag → operate → substitute → state**. To present a new dataset with the same pattern:

1. **Identify** the appendix or table with a label and number (e.g., "Appendix G" / "Table 1").
2. **Supply** a noun-phrase caption naming the DV, its units, and the population sampled.
3. **Specify** how many conditions are compared and name each one in single quotes.
4. **Flag** any decoding issue the reader must know before reading the numbers (outliers, missing data, asterisks).
5. **Flag** any unit conversion or transformation that altered a raw entry.
6. **Operate** by writing the algebraic formula for the first statistic (μ, then SD, or any other chosen statistic).
7. **Substitute** the group 1 sum and n, giving a rounded result plus a precision tag in parentheses.
8. **Mirror** the substitution and result for group 2 so the two conditions sit side by side.
9. **Close** the descriptive block and announce the inferential block with its own heading.
10. **Identify** the chosen inferential test and **flag** any cases excluded before the test ran.

The rhythm is *label-then-number-then-flag-then-formula-then-result-then-parallel-group-then-next-test*; that is the entire replication key.
