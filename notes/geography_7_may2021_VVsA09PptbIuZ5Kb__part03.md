## What This Section Does (content sequence)

This is the **References / Bibliography** section, so its "content moves" are citation moves, ordered by evidentiary role:

1. **Primary data sources first** (census, EPD river, EPD beach, HKU pollution) — sets the empirical foundation the analysis rests on.
2. **Parameter / variable definitions** (DO, RQI, nitrates, phosphorus) — sets the conceptual vocabulary so the reader can interpret the data.
3. **GIS / software source** (ArcGIS) — names the mapping tool so figure provenance is traceable.
4. **Methodology handbooks** (Cool Geography fieldwork, OECD composite indicators) — backs up the analytical procedures chosen.
5. **Statistical-test references in matched pairs** (Pearson + its critical values; Spearman + its significance table) — bundles each test with its lookup table so the reader can verify thresholds.

**Why this order:** the bibliography front-loads *what was measured and where*, because the rest of the section only makes sense once the evidence base is anchored. Defining terms next lets a marker cross-check vocabulary. Tools come before methods because the reader must know the instrument before judging the procedure. Statistics sit last because they are only meaningful once data, variables, and method are established. Within the statistics block, pairing each test with its critical-value table means the marker never has to flip far to verify a number.

## Express-Idea Vocabulary

Because this is a bibliography, the "vocabulary" is the **citation-grammar** that signals provenance and traceability:

- **Source-attribution connectors:** dash `" - "` (e.g. "Fact Sheet for Tertiary Planning Units **-** 2011 Hong Kong"), pipe `"|"` (e.g. "Success Stories **|** Environmental Protection Department"), em-dash `" — "` (e.g. "Nitrates in rivers **—** European Environment Agency") — each marks the pivot from *work title* to *issuing body*.
- **Date / temporal markers:** "**Accessed:** 22 June. 2020", "**Accessed: 5** Jan. 2021", "1 Apr. **2020**" — used to fix the snapshot of the web resource.
- **Evidence-handling verbs / nouns (within titles):** "Fact Sheet", "Source", "Quality Index", "Critical Values", "Significance of …" — these nouns flag *what kind of evidence* the citation supplies.
- **Authoritative-body labels:** "EPD", "HKU", "USGS", "OECD", "European Environment Agency", "Esri", "Statistics Solutions" — used as provenance tags that compress the credibility argument into two-to-four capitalised letters.
- **Type-classifying verbs inside titles:** "About ArcGIS", "Handbook on Constructing", "Phosphorus and Water", "Dissolved Oxygen" — gerund / bare-noun constructions that classify the citation as descriptive or definitional rather than empirical.

## How to Explain an Idea (replication steps)

The pattern this section relies on is **topical-cluster ordering: group citations by their evidentiary job, not alphabetically**. To replicate the same bibliography logic for a different investigation, follow these steps:

1. **Inventory every external source you actually consulted**, splitting them into five buckets: (a) primary datasets, (b) variable/parameter definitions, (c) tools and software, (d) methodology handbooks, (e) statistical tests and their lookup tables.
2. **Order the buckets in the same evidentiary sequence used here**: primary data → parameter definitions → tools → methodology → statistics. Reason: data first anchors facts; definitions let the marker interpret vocabulary; tools justify figure provenance; methodology justifies procedure; statistics comes last because it presupposes everything before it.
3. **Within the primary-data bucket, order by geography/scale**: start with the most local source (the specific district census) and end with regional context sources. Reason: local-first sequencing mirrors how the analysis moves from site to region.
4. **Within the parameters bucket, pair related items**: nutrient citations together, water-quality indices together. Reason: the marker can compare definitions side-by-side rather than hunting.
5. **Within the statistics bucket, pair each test with its critical-value table as an inseparable unit**, placing the explanation-source immediately before the table-source. Reason: the reader needs both to verify every coefficient quoted in the analysis.
6. **For each entry, standardise the micro-format**: `"Title - Source Body." [Publication date if available,] URL. Accessed: D Mon. YYYY.` Reason: uniformity signals rigour; inconsistent formatting is a hallmark of weaker bibliographies.
7. **Close with the most recent or most general reference last** (here, the second Spearman significance citation ends the list). Reason: the terminal entry should be a verifier the marker can cross-check quickly, leaving a tidy impression.
