## What This Section Does (content sequence)

This is a **cost-adjustment block** with the following ordered moves:

1. **Raw unit cost stated first** — sets the baseline number before any adjustment (because every downstream calculation depends on this anchor).
2. **Commercial context (the product carrying the component)** — grounds the chip in a real priced device, motivating why precision matters (because it foreshadows that this cost will feed a larger price model).
3. **Geographic/complicating factor introduced with "But since…"** — pivots to a constraint (because raw cost must be modified when sourcing geography changes).
4. **Authoritative rate cited** — supplies the percentage needed for the operation (because without a sourced rate, the adjustment has no grounding).
5. **Worked calculation displayed** — turns prose numbers into an explicit operation (because showing the math demonstrates rigour and lets the reader verify).
6. **Scale/volume evidence** — anchors the adjusted cost against real-world output (because a tiny per-unit number only matters if multiplied by large volume).

The logic: **anchor → motivate → introduce constraint → source constraint → apply constraint → evidence scale.**

## How to Explain an Idea (replication steps)

This section relies on the pattern: **anchor cost → motivate via consumer price → introduce geographic constraint with "But since…" → source the rate with "According to…" → display worked arithmetic → evidence scale.**

Numbered replication steps:

1. **Open with the raw unit cost.** State the component and its estimated production cost as a single dollar figure before any modification. (e.g. *"[Component] has an estimated production cost of $[X]."*) This anchors every later number.

2. **Ground the component inside a real priced product.** Name the product that uses it and give its starting retail price. This shows the cost is commercially meaningful and not abstract.

3. **Pivot with a concessive clause.** Write *"But since [producer] is a manufacturer located in [country]…"* to introduce the new sourcing geography as a complication. The "But" must signal a constraint, not a contradiction.

4. **Cite the rate with an authority marker.** Use "According to [source], [item] has a tariff of [X%]." The source must be named (even loosely) so the rate is not asserted as your own opinion.

5. **Show the arithmetic explicitly.** Display *"X + (X × rate) = adjusted cost"* rather than just stating the result. The visible operation is the proof.

6. **Anchor the adjusted figure with scale.** Cite a verifiable platform/figure showing volume (sales, shipments, users) so the per-unit adjusted cost has weight.

The chain is: **anchor → motivate → constrain → source → calculate → scale.** Each move's output is the input the next move requires (raw cost feeds motivation, motivation justifies the constraint, constraint demands a rate, rate drives arithmetic, arithmetic feeds a model that needs scale).
