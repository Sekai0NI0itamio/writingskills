## What This Section Does (content sequence)

This is a **results-and-trend-discussion** micro-section. The ordered moves are:

1. **Present raw trial data in a table** (concentration with uncertainty, three trials, mean with uncertainty). *Sets up:* gives the reader numbers to anchor the verbal claims that follow.
2. **State the primary trend** (negative correlation between the two variables). *Sets up:* primes the reader to look at direction of change before magnitude.
3. **State a secondary comparative observation** (one condition's values exceed another's). *Sets up:* raises the explanatory gap — the reader now asks "why larger?" — which the next move closes.
4. **Cite a theoretical relationship to justify the comparison** (equation 2, proportionality). *Sets up:* converts a visual observation into a defended claim by linking data to model.
5. **Note the formatting/rounding convention** used on the values. *Sets up:* housekeeping that closes the section without introducing new claims.

**Why this order works:** data → primary claim → secondary claim → theoretical justification → procedural housekeeping. Each move supplies the justification or context the next move consumes; reversing any pair breaks the logic (e.g., citing the model before stating the trend would feel unmotivated).

## How to Explain an Idea (replication steps)

The pattern used here is **observation → primary trend → comparative observation → theoretical justification → procedural close**. To replicate it on a new idea:

1. **Lay out the data.** Present three trials of the dependent measurement against an independent variable, with propagated uncertainty, in a table.
2. **Read off the primary trend.** Open with "By observing [Tables X & Y], we can see that there is a [direction] correlation between [independent] and [dependent]." This sentence's job is only to name direction.
3. **Add a secondary comparison.** Use "Furthermore, [dependent] for [condition A] appear to be [higher/lower] on average than those of [condition B]." This sentence's job is to raise the implicit "why?"
4. **Close the explanatory loop with a model.** Use "Looking at ([equation ref]), we can see that [dependent] is proportional to [independent]^n, so this [observation] is mathematically comprehensible." This converts the visual pattern into a defended claim.
5. **State a housekeeping convention.** Close with a passive sentence specifying the rounding rule ("formatted to N significant figures") so the section ends without a new claim.
