## Paragraph Flow (move by move)

**Paragraph 1** (equations + observation block, treated as one paragraph because the logic flows continuously)

1. **Equation display + enthalpy value** — *Evidence + Claim (quantitative anchor).* "AH = -143 kJmol" sets the theoretical/equation value the experiment must be compared to.
2. *Hands forward by:* establishing the reference number — the next sentences will be measured against it.
3. **Observation — combustion quality** — *Evidence (qualitative).* "There was complete combustion, and no soot was produced, nor pollutants were observed." Confirms the reaction behaved as expected.
4. *Hands forward by:* validity statement — once clean combustion is asserted, the next move can compare flame behaviour to the methanol reference already implied.
5. **Observation — flame comparison** — *Comparison.* "it was lower than that of methanol." Continues the "what we saw" strand.
6. *Hands forward by:* finish-the-picture logic — having covered combustion completeness, the writer now moves to the *end-of-experiment* observation.
7. **Observation — late-stage flame** — *Evidence (temporal condition).* "At the end when the temperature became constant, the flame was dim, but present because the wick was still wet with ethanol."
8. *Hands forward by:* closure of the observation block — now the narrative can shift from *what was seen* to *what was measured*.
9. **Measurement statement** — *Evidence (quantitative).* "The average temperature rise of water was 59.5°C."
10. *Hands forward by:* cause → the measurement triggers the calculation in the next clause.
11. **Calculated result + source pointer** — *Claim (derived value).* "the enthalpy of combustion for ethanol was 142.81 kJmol™." Introduces the experimental value that must now be judged.
12. *Hands forward by:* evaluative pivot — a number alone is just data; the next sentence compares it to the literature.
13. **Comparison to literature + judgement** — *Verdict (with evaluation verb).* "This is was surprising because it is significantly lower than the literature value."
14. *Hands forward by:* explanation gap — having flagged a discrepancy, the next sentence offers a mechanism (rate of temperature change).
15. **Mechanism for the discrepancy** — *Unpack (cause for verdict).* "at around 400 seconds, it started to slow down." Explains *why* the experimental value was low — heat loss once the reaction slowed.

## What This Section Does (content sequence)

This is a **results-and-initial-discussion** section, not a pure methods or pure analysis section. It blends raw observation, calculation, and judgement in one block.

Order of moves and why:

1. **Reference equation + theoretical ΔH** — *sets up* the benchmark.
2. **Qualitative combustion observation** — *sets up* validity (you can only trust a number if combustion was complete).
3. **Comparative flame observation** — *sets up* linkage to prior experiment (methanol).
4. **End-state observation** — *sets up* honesty about the run (wick still wet).
5. **Quantitative measurement (ΔT)** — *sets up* the calculation.
6. **Calculated experimental ΔH** — *sets up* the comparison to the benchmark from step 1.
7. **Verdict (lower than literature)** — *sets up* the "why" of the next sentence.
8. **Mechanism (temperature rise slowed at ~400 s)** — *sets up* a cause for heat loss.

Generalised sequence another student could replicate: **equation/benchmark → qualitative validity → comparative observation → end-state caveat → measurement → calculated result → verdict against benchmark → mechanism explaining verdict**. The logic is always: *establish what should happen, show it happened cleanly, show what you measured, compare, then explain any gap.*

## Express-Idea Vocabulary

- **Specification of calculation source:** "After doing the necessary calculations (shown below)" — points to where the maths lives without re-doing it.
- **Evidence handling (temporal):** "at around 400 seconds" — anchors a mechanism to a time on the graph.
- **Mechanism verb:** "started to slow down" — frames the discrepancy as a *rate change*, not a static error.
- **Verdict evaluative:** "This is was surprising because" — names a feeling *and* a reason in one connector.
- **Comparison connective:** "lower than that of methanol" — implicit "whereas" via comparative + "that of".
- **Causality connector:** "because the wick was still wet with ethanol" — explains an end-state observation.
- **Quantifier + unit pattern:** "59.5°C", "142.81 kJmol™", "AH = -143 kJmol"" — three numbers in one block doing three different jobs (measured, derived, reference).
- **Authority reference:** "found from the IB chemistry data booklet" — names the source of the literature value.
- **Hedged observation:** "nor pollutants were observed" — negative evidence, qualified.

## How to Explain an Idea (replication steps)

The pattern this section uses for the **discrepancy** is: **benchmark → measured value → verdict (surprise/agreement) → temporal mechanism that caused the gap.**

To explain a new idea with the same pattern:

1. **State the theoretical/expected value first.** Write the equation and the literature ΔH (or equivalent reference figure) at the top.
2. **Report the qualitative run** in a single sentence that asserts completeness ("complete combustion / clean reaction / no side products").
3. **Report one comparative observation** linking this run to the prior run in the series ("lower/higher than that of [previous substance]").
4. **Report the raw measurement** with its unit (ΔT, mass change, volume, etc.).
5. **State the derived calculated value** as a separate sentence, naming the quantity.
6. **Deliver a verdict sentence** using an evaluative adjective ("surprising / close / significantly lower") tied by "because" to the next sentence.
7. **Give the mechanism for any gap** as a temporal clause ("at around X seconds / once Y happened, the rate slowed / heat escaped because…").
