## What This Section Does (content sequence)

This is a **raw-data results table**. The ordered moves are:

1. **Column header strip / variable definition** — "Trial    Ambient     Reflected      Albedo           Average Albedo" — first because the reader cannot interpret any number without knowing the column it sits in.
2. **Site (sampling-location) labels** — "Site A", "Site B", "Site C", "Site D", "Site E1 (Natural)", "Site E2 (Concrete)" — second because raw numbers must be grouped by the independent variable (location/surface) before any comparison is possible.
3. **Trial numbering within each site** — the integer column "1, 2, 3, 4, 5" — third, to declare sample size and to allow within-site averaging.
4. **Raw measurement triplet per trial** — Ambient, Reflected, Albedo — fourth, the primary observations. These must precede the summary so the summary can be checked against them.
5. **Per-site Average Albedo** — "53%", "25%", "35%", "55%", "7%", "8%" — last, summarising the five trials and enabling cross-site comparison in one glance.

The order sets up: keys → contexts → repetitions → raw data → summary. A student replicating this for a different investigation should: define variables across the top → group rows by the independent variable → repeat trials → record raw numbers → place a single summary cell on the middle row of each group.

## Express-Idea Vocabulary

The section uses **no prose connectives** because it contains no sentences. The "vocabulary" that does the logical work is the table grammar:

- **Sequencing (column order = reading order)**: "Trial    Ambient     Reflected      Albedo           Average Albedo" — left-to-right placement tells the reader that repetition index precedes the raw variables, which precede the derived ratio, which precedes the summary.
- **Specification (parenthetical annotation)**: "(Natural)" after "Site E1" and "(Concrete)" after "Site E2" — quoted: "Site E1 (Natural)" and "Site E2 (Concrete)". The parenthetical specifies the surface condition without breaking the row label.
- **Grouping (vertical alignment under a site label)**: "Site B" sits directly above its five trials; that alignment is the mechanism by which the reader knows those trials belong to B.
- **Summary (single value in a dedicated column)**: the unlabelled integer "53%" in the Average Albedo column acts as the verdict for Site A; likewise "25%", "35%", "55%", "7%", "8%" for the other sites.
- **Incomplete-data marker**: Trial 5 of Site E1 has the Albedo cell blank ("74          ") — the missing entry is itself the message.
- **No contrast/concession connectives** ("however", "whereas", "although") appear because no argument is being made; the table only presents numbers.

## How to Explain an Idea (replication steps)

The pattern this section relies on is **multi-context raw-data presentation with a derived-ratio column and per-context averaging**. The replication steps are:

1. **Define the column header strip first**: write across the top (a) one repetition index, (b) two raw measurements, (c) one derived ratio, (d) one summary statistic — in that exact left-to-right order. The reader cannot decode any cell without this key.
2. **Choose N sampling contexts** (sites, plots, samples, trials-of-a-condition) and label each with a short proper noun, e.g. "Site A". Add a parenthetical condition only when a treatment is being compared across otherwise-identical contexts.
3. **Repeat the trial structure a fixed number of times** within each context (here, 5). Repetition is the reader's only signal of sample size; do not vary the count across contexts unless you state why.
4. **Record, per trial, the two raw values and the derived ratio** (here, Ambient, Reflected, Albedo %). Derived ratios must sit in their own column so the reader can both verify them from the raw values and average them.
5. **Place a single summary cell** (the mean of the derived-ratio column) on the middle row of each context-block in the rightmost column. The middle row anchors the summary visually without needing the word "average".
6. **Leave cells empty rather than fabricate** when a measurement failed. A blank cell in the derived-ratio column tells the reader the trial is unusable; do not write "0" or "—" in its place.

This pattern lets a reader scan vertically by context and horizontally by trial without reading prose. Apply it to any experiment with several sampling locations, repeated measurements per location, and one derived ratio per trial.
