Record [variable] every [interval]. Record until [termination]. Repeat steps [n] more times. Repeat steps [n] for [next variable]."

   - Slot 1: imperative verb + enumerated apparatus list (3 items).
   - Slot 2: imperative + measuring tool + volume + transfer verb + destination vessel.
   - Slot 3: imperative + volume + tool + container.
   - Slot 4: imperative + spatial preposition ("under/above/in").
   - Slot 5: imperative + variable + "record the value".
   - Slot 6: imperative + ignition verb + safety clause.
   - Slot 7: imperative + timer verb.
   - Slot 8: imperative + variable + interval + "until termination".
   - Slot 9: repetition directive + count.
   - Slot 10: variable substitution directive.
2. **How to fill with a different idea**: pick a calorimetry-style or rate-of-reaction setup; slot 1 = name three pieces of glassware/mounting hardware; slot 2 = choose a liquid reactant and a graduated vessel; slot 3 = choose a second liquid (catalyst, indicator, etc.); slot 5 = choose a measurable variable (mass, pH, gas volume); slot 6 = state ignition/mixing trigger with one safety verb; slot 8 = state a visible endpoint ("until solution turns colourless").

## How to Explain an Idea (replication steps)

The pattern this section relies on is a **physical-procedure-with-tabbed-safety** structure: **hardware → liquid loading → spatial alignment → baseline → trigger → interval sampling → termination → repetition → variable substitution → hazard register**.

Replication steps for any new lab procedure:

1. **Begin with apparatus assembly in one imperative sentence listing three named items plus a visual reference** ("the way shown in diagram X"); this establishes hardware before any chemical act.
2. **State volume measurement of the first liquid using a named graduated tool and transfer verb** to a named vessel; this converts a quantity into a physical object in the system.
3. **State volume measurement of the second substance into its own container**, using a different tool, to keep reagents separate until ignition.
4. **Use a "Place X under/above Y" sentence** to convert separate items into a connected system — this is the cause that enables energy transfer.
5. **Record a baseline of the dependent variable in one short sentence** before any reaction starts, anchoring the comparison.
6. **Issue a two-step ignition command** (source-then-fuel) **followed by a "Note that… so…" clause** that flags safety at the highest-risk moment.
7. **State timing: "Start the stopwatch."** as its own one-line imperative so the reader mentally resets.
8. **State the sampling interval in a single sentence** ("every X seconds").
9. **State the termination condition with "until"** tied to a visible endpoint (fuel gone, colour change, mass steady).
10. **Issue a repetition count** ("Repeat steps 1-9 four more times") to signal reliability.
11. **Issue a variable substitution** ("Repeat steps 1-10 for [fuel B] and [fuel C]") to signal comparison.
12. **Move to a separate visual/tabular hazard register** using three columns (Hazard / Harm / Precaution) and two minimum rows; each row uses the triplet "[Substance] are [property] / [Harm] / [Precaution verb] [action]." This separates narrative procedure from scannable risk information.
