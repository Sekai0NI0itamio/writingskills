*Hand-off:* offers two procedural alternatives; the next sentence must therefore answer "what happens if you did both?" — i.e. it follows by *consequence*.

## What This Section Does (content sequence)

This is an **error-reduction / methodological-improvement** paragraph. The order of moves is:

1. **Propose procedural adjustments** (set up the reader's mind that changes are coming).
2. **State the benefit of those adjustments** (close the first proposal cleanly so it doesn't bleed into the next).
3. **Pivot with an additive connector and introduce a second improvement** (avoid overloading the first proposal).
4. **Identify the limitation of the existing method** (justify *why* a new tool is needed).
5. **Quantify that limitation with concrete evidence** (give the problem a number so it feels real, not rhetorical).
6. **Deliver a comparative verdict** showing the new tool removes the named limitation (resolve the argument).

**Why this order works:** each move presupposes the one before it. Benefit (2) needs adjustment (1); a new proposal (3) needs the previous benefit closed; a justification (4) needs a method on the table; evidence (5) needs a stated limitation; a verdict (6) needs both the evidence and the proposed tool. Skipping any step leaves the reader asking "but why?" or "so what?" — the moves are strictly sequential.

A student replicating this on a different topic (e.g. pH experiment improvements) would: (1) name two physical adjustments, (2) say they reduce error, (3) add a new tool via "Moreover", (4) state the old tool's flaw, (5) give the flaw as a number, (6) close with why the new tool wins.

**SKELETON C — "Specific evidence → comparative verdict" (sentences 5–6)**
`"In comparison, the [old tool] was only [number + unit], meaning that it [fails in specific way]. The use of [new tool] to [measure the same quantity] would make it more accurate as such limitations are very minimal when [reason]."`

1. *Slot 1* uses "In comparison" + a numeric instance of the bottleneck + a "meaning that..." unpacking the consequence. *Slot 2* uses a "The use of [X]... would make it more accurate as..." verdict grounded in a physical reason.
2. **How to fill with a different idea:** slot 1 — quote the spec sheet of your old instrument (e.g. "only 240 Hz", "only ±0.5 °C") and translate it into a concrete failure mode ("skips intervals", "blurs the peak"). Slot 2 — name the physical property of the new tool that avoids that failure (speed of light, higher sampling rate, digital readout).
3. **Original fill:** "In comparison, the iPhone camera was only 60 FPS, meaning that it skips small intervals of time... The use of light gates to measure the time... would make it more accurate as such limitations are very minimal when utilising the speed of light."
4. **Demo fill (different idea):** "In comparison, the analogue thermometer was only accurate to ±0.5 °C, meaning that it blurs the exact peak temperature. The use of a digital thermocouple to record the maximum value would make it more accurate as such limitations are very minimal when sampling at 10 Hz."

## How to Explain an Idea (replication steps)

This section uses the pattern **Improvement 1 → its payoff → Improvement 2 → named flaw of the old method → numerical evidence of the flaw → verdict that the new method kills the flaw**. Replicate it in six numbered steps:

1. **Open with a concrete physical adjustment.** Name two cheap, reversible tweaks to the apparatus. Use imperatives joined by "or".
2. **State the benefit in hedging language.** Use "would likely minimise/reduce my [error type] for the [quantity]" so the claim is committed but not over-claimed.
3. **Pivot with an additive connector and introduce a second, different improvement** (a new instrument, not another physical tweak). Use "Moreover, another change... is to introduce [X]."
4. **Name the single limitation of the old method in a definition-style sentence.** Use the formula "The limitation of using [old tool] is that it is limited to [constraint]." Do not give the number here — only the category of limitation.
5. **Quantify the limitation as evidence.** Use "In comparison, [tool] was only [number + unit], meaning that it [specific failure mode]." This converts the abstract flaw into something measurable.
6. **Close with a comparative verdict.** Use "The use of [new tool] to [verb + quantity] would make it more accurate as [reason rooted in physics]." The reason must explain *why* the new tool escapes the named numerical flaw — otherwise the paragraph ends in assertion.
