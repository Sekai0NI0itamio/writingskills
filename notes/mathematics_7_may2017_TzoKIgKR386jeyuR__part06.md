## What This Section Does (content sequence)

1. **Residual rationale** — a one-line carry-over reminding the reader why accuracy matters (tail claim).
2. **Visual + source** — a figure caption immediately followed by a citation, so the method is *shown* and *sourced* in the same beat.
3. **Purpose statement applied to this model** — the generic tool (Euler's Method) is named inside the specific model (DSIRM) and told *what* it will approximate (S/I/R counts over time). Sets up the need for a formula.
4. **Consequence bridge ("then be derived")** — turns the forward-looking *will be used* into the deliverable *the equation*.
5. **Worked display, one row per state variable** — the formula is unpacked per compartment so each line can be checked; this is where the approximation mechanism becomes concrete.
6. **Numbered label** — assigns an equation number and restates the context, sealing the section as a citable unit.

The order matters because each move answers the question the previous one raised: *why does accuracy matter?* → *what does the method look like?* → *who says so?* → *what will it do here?* → *show me* → *label it so I can come back to it.*

## Paragraph Skeletons (replicable templates)

**SKELETON A — "Visual + Purpose" paragraph**

> *"Figure N — A graphical illustration of [Tool]. (Source: [Author, Title, Publisher, Page].) In [specific context], [Tool] will be used to approximate how [quantity] changes over [span]."*

1. **Slots & shapes**
   - Slot 1: figure caption, noun phrase + "graphical illustration of [Tool]."
   - Slot 2: parenthetical citation, full bibliographic tuple.
   - Slot 3: application sentence, future passive ("will be used to approximate") + object + temporal phrase ("over time").
2. **How to fill with a different idea**
   - Slot 1: pick a numerical or graphical method (e.g. trapezoidal rule, Newton's method). Use the exact phrase *"A graphical illustration of …"*.
   - Slot 2: keep the citation shape — Author, *Title*, Place, Publisher, page.
   - Slot 3: name a model or context you are investigating, then state which quantity the tool will approximate (counts, areas, slopes) and over what span (time, iterations, intervals).
3. **Original fill**
   *"Figure 1 — A graphical illustration of Euler's method. (Source: Blythe, Peter. Mathematics for the International Student… p. 233.) In a DSIRM, Eurler's Method will be used to approximate how the number of people in the S, I, and R change over time."*
4. **Demonstration fill with a different idea**
   *"Figure 2 — A graphical illustration of the trapezoidal rule. (Source: Stewart, James. Calculus: Early Transcendentals, 8th ed., Boston: Cengage, 2016, p. 406.) In the cooling-model investigation, the trapezoidal rule will be used to approximate how the cumulative heat loss of the metal rod changes over the first 60 seconds."*

**SKELETON B — "Bridge to derivation" sentence**

> *"The following [noun phrase] can then be derived for [context]."*

1. **Slots & shapes**
   - Slot 1: a single demonstrative determiner (*the following*) + singular noun phrase naming the artefact to come (equation, expression, formula, set of relations).
   - Slot 2: the specific model or case the artefact belongs to.
2. **How to fill**
   - State the consequence marker *can then be derived* — never drop *then*; it is the load-bearing connective.
   - Keep it one sentence; this is a hinge, not an explanation.
3. **Original fill**: *"The follwing equation can then be derived for the DSIRM."*
4. **Demonstration fill**: *"The following closed-form expression can then be derived for the logistic growth model."*

**SKELETON C — "Numbered equation caption"**

> *"Equation [N] — [equation] for [context]."*

1. **Slots & shapes**
   - Slot 1: label *"Equation"* + integer.
   - Slot 2: a generic noun for the artefact (*Equation / Expression / System*) + *"for"* + the model name.
2. **How to fill**
   - Use a colon or em-dash after the number; never write a full sentence.
   - Repeat the model's name verbatim from earlier in the section so the reader can locate it without rereading.
3. **Original fill**: *"Equation 6 — Equation for the DSIRM."*
4. **Demonstration fill**: *"Equation 3 — System for the cooling-model investigation."*

## Express-Idea Vocabulary

- **Sequencing / consequence transition**: *"can then be derived"* in "The follwing equation can then be derived for the DSIRM." — links the purpose statement to the formula display.
- **Purpose / function (future passive)**: *"will be used to approximate"* in "In a DSIRM, Eurler's Method will be used to approximate…" — declares what the method does in this model.
- **Temporal specification**: *"change over time"* in "…how the number of people in the S, I, and R change over time." — names the independent variable of the approximation.
- **Visual / referential labelling**: *"A graphical illustration of"* in "Figure 1 — A graphical illustration of Euler's method." — frames the figure as a referent, not a decoration.
- **Authority handling**: *"Source: Blythe, Peter."* — packs the entire bibliographic trust into a single parenthetical so the figure carries weight.
- **Locator / naming**: *"Equation for the DSIRM"* in "Equation 6 — Equation for the DSIRM." — re-uses the model name as a stable handle for later cross-reference.

## How to Explain an Idea (replication steps)

The pattern is **Visual-with-Source → Purpose-Applied-to-Context → Consequence-Bridge → Worked-Display → Numbered-Label**.

Step 1 — **Cite the tool visually and source it.** Open with a figure whose caption is *"A graphical illustration of [Tool]."* and immediately follow with a parenthetical full source (Author, Title, Place, Publisher, page). One beat, two moves.

Step 2 — **State the purpose inside your own model.** Write one sentence beginning *"In [your context], [Tool] will be used to approximate how [quantity] changes over [span]."* This transplants the generic tool into your specific investigation and tells the reader what is being solved for.

Step 3 — **Bridge with a consequence sentence.** Write exactly: *"The following [noun] can then be derived for [your context]."* The word *then* is mandatory — it converts the Step-2 promise into the Step-4 deliverable.

Step 4 — **Display the worked formula, one row per state variable (if applicable).** Unpack the promised equation into as many lines as there are compartments or components, so each can be checked independently.

Step 5 — **Close with a numbered caption.** Write *"Equation [N] — [Equation / System] for [your context]."* Re-use the model's name verbatim from Step 2 so the reader can cite the block later.
