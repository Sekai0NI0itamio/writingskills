## What This Section Does (content sequence)

This is a **method/sampling** section that performs the following ordered moves:

1. **Tool/medium of capture** — names the source (Google Maps/StreetView).
2. **Data handling step** — says where the raw counts were deposited (spreadsheet).
3. **Aggregation rule** — explains how raw units combine into analytical units (quadrants summed into sectors).
4. **Methodological classification** — names what the procedure *is* (hybrid: random + targeted).
5. **Evidence pointer** — directs the reader to the figure (table 1).
6. **Specific-case application** — re-runs the procedure on one named location (Tower Hamlets) using a second method (in-person recount).
7. **Statistical verdict** — converts the figures into a confidence-based target sample size.

**Why this order:** each move hands the reader the premise the next move needs. You cannot classify a methodology (4) before you have stated its steps (1–3); you cannot point to evidence (5) before the evidence exists; you cannot compute a sample target (7) before the instance population has been quantified (6). A different topic (e.g. biodiversity counts, survey responses) should follow the same chain so the reader is never asked to evaluate a number whose source has not yet been named.

## How to Explain an Idea (replication steps)

The pattern this section relies on is a **"data-chain explanation"**: *capture → aggregate → classify → display → instance → compute*.

Step-by-step instructions to replicate it on a new idea:

1. **Name the capture medium first** in a short noun phrase, so the reader knows the source of every number that follows.
2. **State the destination of the raw data** ("put into a spreadsheet / database / log") — the reader now has a container.
3. **Inside a "where" clause, state the aggregation rule** that turns raw units into the analytical units the reader will actually see (quadrants → sectors).
4. **Compress the procedure into a one-line methodological label** introduced by "As such," naming the technique as a blend of two approaches.
5. **Point to the figure** that visualises the totals ("This is portrayed in table X").
6. **Pivot to a single named sub-area** ("In [location] …") and describe a *second* pass using repetition verbs ("traversed yet again and X re-counted"), then re-anchor the output to the same figure.
7. **Convert the populated figure into a statistical verdict** introduced by a second "As such," giving a confidence percentage and the final calculated target as one number + unit.
