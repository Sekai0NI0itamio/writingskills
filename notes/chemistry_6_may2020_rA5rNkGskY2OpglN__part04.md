## What This Section Does (content sequence)

This is a **methodology / control-variables section** delivered as a paired apparatus–justification table. The moves occur in this order:

1. **Apparatus inventory first** — lists *what* is used, with uncertainties and quantities. This establishes the physical setup so the reader has objects to anchor each variable to.
2. **Dependent variable named** — "amount of energy" tells the reader the *target of measurement*, so the controls that follow have a purpose (ensuring energy values are comparable).
4. **First-order control (input quantity)** — amount of fuel per trial. Sets up the logical premise: *same fuel mass = fair enthalpy comparison.*
5. **Geometric control** — distance between flame and beaker. Logical next step because even identical fuel burns differently with different geometry.
6. **Wick/flame-source control** — wick dimensions. Logical because the geometry control assumed a stable flame source.
7. **Medium control** — water purity. Closes the loop by controlling the substance being heated.

**Why this order works:** it moves from *input* (fuel) → *transfer geometry* (distance) → *flame source* (wick) → *receiving medium* (water), tracing the path of thermal energy from production to absorption. A student replicating the sequence should follow the **energy pathway**, not a random list.

## Paragraph Skeletons (replicable templates)

**Skeleton A — "Controlled Variable Justification Row"**
SKELETON: "[Controlled variable]. By [specific procedural action], [consequence: what this guarantees or why it matters]."

1. *What each slot holds:*
   - Slot 1: a noun-phrase controlled variable (e.g., "Distance between the flame and the beaker").
   - Slot 2: a "By + gerund" action describing the concrete lab procedure.
   - Slot 3: a result clause beginning with "thus/therefore/so" or explaining the underlying physics.
   - *Grammar shape:* declarative, short, often one to three sentences; embedded causal reasoning.

2. *How to fill with a different idea:*
   - Slot 1: pick any variable that could vary between trials of a comparative experiment.
   - Slot 2: state the *specific* step a student performs to keep it constant (e.g., "using the same model of pH probe").
   - Slot 3: give the *reason* the variation would matter (e.g., different probes drift differently).

3. *Original filled version:* "The distance between the crucible and the beaker. By maintaining the same experimental setup with the same apparatus… approximately the same amount of heat will escape every time."

4. *Demonstration fill (different idea — biology respiration IA):* "Temperature of the water bath. By submerging each respirometer in the same thermostatically controlled bath at 25 °C. This ensures that any change in gas volume can be attributed to respiration rather than thermal expansion."

## How to Explain an Idea (replication steps)

This section uses the pattern: **controlled variable → concrete procedural action → causal consequence (why the control matters).**

To explain a NEW idea (e.g., a different controlled variable in any comparative lab), follow these numbered steps:

1. **Name the variable** as a label (noun phrase). *Action:* ask, "What could differ between trials even if I do the main procedure identically?" Write that as a label.
2. **Translate the variable into a procedural action** that holds it constant. *Action:* begin the sentence with "By + gerund" and name the *specific physical act* (same model, same volume, same source, same distance). Avoid vague verbs like "control" — be concrete.
3. **State the consequence** that the control produces. *Action:* use "thus" or "therefore" to link the action to a measurable outcome (e.g., "the same amount of heat will escape," "results will be comparable").
4. **Optional fourth step — explain the underlying physics** when the consequence is non-obvious. *Action:* add a sentence beginning "Different [things] can have [variation] and thus [impact on the dependent variable]." This is the move used for water impurities.
5. **Place the row in the energy/transfer pathway** so the rows form a logical sequence from input → transfer → medium. *Action:* before writing the next row, ask, "Where does the variable I just controlled sit along the pathway?" and pick the next slot accordingly.

**Minimal demonstration (one-row replication):**
*Variable:* "Concentration of HCl used."
*By-action:* "By preparing each HCl solution from the same stock bottle within a 10-minute window of use."
*Consequence:* "Thus, any concentration drift due to evaporation is identical across trials."
