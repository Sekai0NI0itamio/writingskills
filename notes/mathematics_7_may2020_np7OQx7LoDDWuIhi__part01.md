## Paragraph Flow (move by move)

**Paragraph 1** (sentences 1–6, the only analytical paragraph; the figure caption is a visual label, not a logical move).

1. **Context carry-over (fragment, tail of previous sentence).** *"rather than providing values which are only proportional to the true values."* — Restates what the prior sentence already established. Hands the reader to the next sentence by *logical consequence*: if proportional values fail, then a true-length measurement is forced.

2. **Deduction / necessity.** *"As such, one dimension of the egg had to be measured."* — Explicit "therefore" move turning the problem into a task. Hands the reader to the next sentence by *specification*: which dimension, and how will it be obtained?

3. **Decision + first procedural step.** *"Deciding to measure the length, the egg was boiled and cut in half along its vertical axis of symmetry, i.e. the middle."* — Picks the variable ("length") and prepares the specimen ("boiled and cut in half"). The "i.e." *rewords* "vertical axis of symmetry" in plain terms. Hands the reader forward by *cause*: now that the egg is halved, the length can actually be read off.

4. **Instrument + measurement result + visual anchor.** *"I then used a 15cm ruler to find the distance between the top and the bottom and that was found to be 5.4cm, represented by the red line in Figure 2."* — Three stacked moves: tool, quantity, reference to a figure. Hands the reader to the next sentence by *problem-shift*: having reported the number, the writer pivots to how trustworthy that number is.

5. **Limitation 1 — human judgment, with rephrasing.** *"It is important to note however that the axis of symmetry was judged subjectively; in other words, I was not able to accurately specify at which point to cut…"* — "however" *contrasts* with the confident value just given; "in other words" *rephrases* the same flaw more plainly. Hands the reader forward by *parallel structure*: another caveat exists, this time about the tool.

6. **Limitation 2 — instrument precision, quantified.** *"Furthermore, the precision of the ruler was 0.1cm, which means that there was an uncertainty of ±0.1cm in the measurement."* — "Furthermore" extends the previous concession; "which means that" turns a raw precision into a *consequence* (an uncertainty value) usable in later error analysis. ## What This Section Does (content sequence)

This is a single-paragraph **method + uncertainty micro-section**. Its moves in order:

1. **Inherit the justification from the paragraph above** (the tail fragment) so the measurement is not unmotivated.
2. **State the requirement** that the previous reasoning forces ("had to be measured").
3. **Choose the specific variable** to measure and **justify the choice implicitly** by naming it first.
4. **Prepare the specimen** in a way that exposes that variable (boil, halve along axis).
5. **Define the axis in plain language** ("i.e. the middle") so a non-specialist reader can picture it.
6. **Execute the measurement**: name instrument, name endpoints, give the value, cross-reference a figure.
7. **Flag a procedural (human) limitation** and *re-explain it* in simpler words.
8. **Flag a second (instrument) limitation** and *convert* the precision into an explicit ± uncertainty that downstream error analysis can use.

The order matters: justification → requirement → specimen prep → raw value → human error → instrument error. The two error moves are stacked because IB examiners expect both *procedural* and *equipment* uncertainty, and the writer needs to have the raw number first before its error sources can be addressed.

## Express-Idea Vocabulary

- **Sequencing / time-order:** *"I then used a 15cm ruler"* — marks the second procedural step after specimen prep.
- **Cause / consequence:** *"As such, one dimension of the egg had to be measured"* — pure "therefore" transition from prior justification.
- **Contrast / concession:** *"It is important to note however that"* — pivots from confident measurement to its flaw.
- **Specification / redefinition:** *"i.e. the middle"* — collapses technical axis name into lay terms.
- **Rephrasing for clarity:** *"in other words, I was not able to accurately specify"* — second clause unpacks the first.
- **Evidence handling / visual cross-reference:** *"represented by the red line in Figure 2"* — anchors the number to a diagram.
- **Explanation verbs:** *"was boiled and cut"* (passive procedure), *"that was found to be 5.4cm"* (passive reporting), *"was judged subjectively"* (passive limitation), *"means that there was an uncertainty"* (passive conversion of precision to ±).
- **Additive connector:** *"Furthermore, the precision of the ruler was 0.1cm"* — stacks a second limitation on the first.

Note the heavy use of **passive voice for every measurement move** ("was boiled," "was found to be," "was judged," "there was an uncertainty") — this is the standard IB method-section register: the object of measurement, not the measurer, is the grammatical subject.

## How to Explain an Idea (replication steps)

The pattern is: **justification → forced requirement → preparation → measurement → human-limit caveat → instrument-limit caveat → quantified ±**.

To replicate with a new idea:

1. **Open with the tail of the previous sentence** that already rejected an inferior approach (e.g. "… rather than values that only scale with the true quantity"). Do not start a new topic; this is mid-paragraph.
2. **Write a one-sentence "As such, [variable] had to be measured" deduction** that names the dimension explicitly. This makes the next action feel forced, not optional.
3. **Choose the variable first, then describe how the specimen was prepared** so it becomes readable — preparation follows the choice, not the reverse.
4. **Rephrase the technical axis in plain words with "i.e."** so a non-specialist reader can visualise the cut/orientation.
5. **Report the measurement in one sentence carrying three payloads**: instrument, endpoints, value, and a figure reference ("represented by the [colour] line in Figure N"). Do not split these across sentences.
6. **Caveat the procedure before you caveat the instrument.** Use "however" and "It is important to note" to signal a shift from value to validity. Restate the same flaw with "in other words" — IB markers reward plain-language unpacking.
7. **Add a second, parallel caveat with "Furthermore"** that names the instrument's precision and *converts it immediately* into a ± uncertainty using "which means that there was an uncertainty of ±…". End the paragraph on this quantified value so the next section can plug it into error propagation.

The defining feature of this pattern is that **every sentence hands forward by exactly one logical relation** (consequence → specification → cause → problem-shift → parallel), so the reader never has to guess why the next sentence exists.
