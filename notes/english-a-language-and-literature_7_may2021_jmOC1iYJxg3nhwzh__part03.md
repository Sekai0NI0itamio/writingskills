## What This Section Does (content sequence)
1. **Alphabetical (or roughly alphabetical) ordering by author surname** — sets up so a reader can locate any source by its first letter; each successive entry is a discrete retrieval unit, not a linked argument.
2. **Per-entry: Author → Title → Container → Date → URL → Accessed date** — the order establishes responsibility first (who said it), then the specific work, then where and when it appeared, then where to verify it, then when the writer verified it. This sequence is fixed by MLA convention because a citation must move from *who* to *what* to *where* to *when verified*; reversing any pair breaks retrievability.

Replicate with a different topic: alphabetise your sources; for each, write a single entry that begins with the credited name, then quotes the work's title, then names the publication venue with its date, then a URL, then "Accessed" + date.

## Paragraph Skeletons (replicable templates)

**Skeleton A — single-author news article:**

1. **Slots:** (i) author surname + comma + first name (proper noun); (ii) title in quotation marks (title-case string); (iii) italicised publication name (proper noun); (iv) full date (day + month + year); (v) full URL; (vi) "Accessed" + day + month + year.

## Express-Idea Vocabulary
- **Structural connectors (separating citation slots):** commas separate author → title → container → date; periods close each slot and the whole entry.
- **Authority/signalling "this is the source":** the inverted "Last, First" name ("Hoffman, Benjamin, and Talya Minsberg"); the corporate-author slot ("Nike.", "The University of Massachusetts Amherst.").
- **Title-signalling punctuation:** quotation marks around the work ("'The Deafening Silence of Colin Kaepernick.'"); italics around the container (publication names).
- **Verification vocabulary:** "Accessed 4 January 2021.", "Accessed 17 November 2020." — closes every entry.
- **Date markers:** full-spelled-out day + month + year ("4 September 2018", "27 May 2020", "25 February 2019") — the consistent format across entries signals the same kind of fact each time.

## How to Explain an Idea (replication steps)
The pattern this section uses is **Authority → Specific Work → Venue → Time → Retrieval → Verification** — an authority-citation chain, not an argumentative one. To credit a source the same way with a new topic:

1. **Name the authority first** — write the surname, comma, first name (or institution/brand name) followed by a period. This is who is on the hook for the claim.
2. **Quote the exact work** — wrap the article/campaign/report title in quotation marks and end with a period. This pins down which output of theirs you used.
3. **Name the container** — italicise the publication, department, or series. This places the work inside the larger venue that hosted it.
4. **Date it** — give day, month, year as originally published. This anchors the claim in time.
5. **Add the URL** — the digital address so a reader can retrace the path.
6. **Stamp the retrieval** — write "Accessed" + day + month + year of when you opened it. This closes the chain and shows the source was live when consulted.
