## What This Section Does (content sequence)

This is a **Methods** section organised in the IB laboratory-report tradition. The order is:

1. **Control variables first (quantified).** Sets the reader's frame: "everything we hold constant so the independent variable is the only thing changing." This justifies the materials list — you need *exactly* the volumes/amounts you just declared.
2. **Materials list, grouped by purpose** (solvents → growth medium → pH adjusters → glassware → biological specimens → measurement tool). Quantities are stated so steps can be carried out without rereading.
3. **Method — safety & setup (steps 1–2).** Personal protection (gloves, hair, shoes) before any chemical handling. Then labelling and grid geometry so replicates are identifiable.
4. **Method — medium preparation (steps 3–4).** Mixing the growth medium, dissolving completely, because undissolved powder invalidates the replicate.
5. **Method — troubleshooting branch (step 5).** A *conditional* fork ("if the powder does not completely dissolve…") which both rescues the procedure and shows the reader the author anticipated failure modes.

**Why this order works:** controls define the targets, materials supply the targets, setup places them in space, preparation realises them chemically, troubleshooting guards them. A student replicating with a different topic should keep the sequence: *quantify what stays the same → enumerate what you need → prepare the environment → execute the variable-changing step → handle the predictable failure*.

## Paragraph Skeletons (replicable templates)

**SKELETON A — Quantified Control Variable Enumeration**
"[Variable 1] should be equal to [quantity with unit]." / "[Variable 2] should have [quantity] mixed and dissolved in it." / "[Variable 3] has to be filled with [quantity]." / "[Number] [organism/object] per [container]." / "All of the [subjects] should be exposed to the same [environmental factor] and [environmental factor]."

1. **Slots:**
   - Slot 1: a single-volume control (e.g. solvent volume). Noun phrase + "should be equal to" + number + unit.
   - Slot 2: a solute amount per container. "Each [container] should have [number] [unit] of [substance] mixed and dissolved in it."
   - Slot 3: a fill specification for a solid substrate. "[Container dimensions] has to be filled with [quantity] of [substrate]."
   - Slot 4: a one-per-container rule. "[Number] [organism] per [container]."
   - Slot 5: a shared-environment closure. "All of the [subjects] should be exposed to the same [factor A] and [factor B]."
2. **How to fill with a different idea:** choose five independent controls you must hold constant in *your* experiment. Give each a number and a unit in the same grammatical frame (X = …, Y = …). Use "should be equal to" for the first, "should have … mixed" for the second, "has to be filled with" for the third, "per" for the fourth, and "same … and …" to close.

## How to Explain an Idea (replication steps)

This section uses a **Specification → Enumeration → Imperative Procedure → Conditional Rescue** pattern. To replicate it for any lab method:

1. **Open with quantified controls.** List 3–5 variables you are holding constant, each as a single sentence with a number and a unit. Use "should be equal to", "should have", "has to be filled with", and close with "all … should be exposed to the same X and Y."
2. **List every physical item.** Group implicitly: liquids, powders, branded preparations, tools, glassware, hardware, PPE, containers, biological specimens, instruments. Quantify each.
3. **Begin the procedure with paired safety imperatives.** Sentence 1: "Gather X and put on Y." Sentence 2: "Tie up Z and make sure to wear W."
4. **Define the spatial grid.** One sentence that labels, specifies the grid geometry ("each row should have … and … per column"), names permissible tools ("… and/or … can be used"), and states placement ("place them in a … area that has access to …").
5. **Move to the main chemical/biological preparation.** Write a measure-and-add sentence with two numbers and a condition. Follow with a corrective rinse sentence ("to remove trace residues of …").
6. **Add the next-stage ingredients with a temporal anchor.** "Add … prior to [next stage]." Pair it with a continuation imperative bound to a success state ("continue … until … has completely …").
7. **Close with a conditional rescue branch.** "If [failure state] does not [desired verb] then [tool/reagent] and [verb], [verb], and [verb] until the [outcome] becomes [adjective]." This shows the reader you anticipated failure and gives them an exit.
8. **Do not explain *why* in this section.** Save reasoning, evidence, and "according to" for the Discussion. The Methods section is a clean imperative voice with embedded numbers; every sentence either controls, lists, or commands.
